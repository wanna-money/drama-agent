# 法术/特效提示词指南 / VFX & Spell Prompt Guide(video-storyboard 参考文档)

> 来源:公众号《怎么写出"一看就是修仙大能"的法术提示词?》(2026)。
> 用途:仙侠/玄幻类短剧的法术、法阵、特效镜头是最费时间调参的环节——写"一个法阵
> 发光"等于没写。本文件给出可直接套用的**法术特效描述公式**与范例,供分镜/prompt
> 阶段在涉及法术、能量特效、法阵类镜头时参考。

---

## 一、核心问题:法术特效提示词必须写清楚五件事

只写"一个法阵发光",AI 不知道这个法阵长什么样、什么颜色、什么动态、什么质感,
自然出不了效果。真正能打出效果的提示词必须覆盖:

**阵纹结构 + 能量流向 + 粒子细节 + 空间动态 + 氛围光影**

少一个,画面就平一层。这五个维度就是"法术特效描述公式"——以后写法术提示词,
按这五个维度往里填内容即可:雷系填电弧/电蛇/雷光粒子;火系填烈焰/火浪/余烬粒子;
冰系填冰棱/冰晶/寒霜雾。不用死记具体范例,记住公式就能自己写出新的一套。

## 二、五个维度的具体化方向

| 维度 | 含义 | 具体化方向举例 |
|---|---|---|
| 阵纹结构 | 法阵的几何形态与图案 | 环形/九宫格/六芒星/太极两仪;阵纹镌刻的图腾符文 |
| 能量流向 | 能量在法阵/角色间如何运动 | 自阵纹迸发、沿轨迹游走、向外扩散、汇聚于阵眼 |
| 粒子细节 | 弥散在空气中的细小视觉元素 | 剑气粒子、灵力波纹、冰晶碎片、燃烧余烬 |
| 空间动态 | 法术对周围空间的影响 | 空间裂痕、扭曲颠倒、冻结万物、地脉震动 |
| 氛围光影 | 整体色调与光效基调 | 体积光、丁达尔效应、能量光晕圈层震荡 |

## 三、范例提示词结构(可直接套用的句式骨架)

```
[人物姿态与引法动作] + [渲染技术标签] + [法阵整体形态与镌刻纹样] +
[阵眼核心特效] + [能量扩散与粒子细节] + [空间影响] + [氛围基调] + [约束]
```

**渲染技术标签**(仙侠国漫 CG 风格固定写法,可直接复用):
"国风国漫CG,UE5,Octane Render,电影级体积光,丁达尔效应,8K高清"

**通用约束(反向提示词)**:
"Q版,手绘草稿,模糊,低分辨率,文字乱码,水印logo,画面过度拥挤,人物畸形,肢体崩坏,
特效平淡,光效微弱,缺乏冲击力"

## 四、按五行/属性分类的关键词速查

| 属性 | 阵纹/形态关键词 | 能量/粒子关键词 | 氛围基调 |
|---|---|---|---|
| 剑/煞气系 | 环形剑阵、剑纹流转 | 剑气粒子、煞气翻涌如海潮 | 肃杀 |
| 火系 | 环形火阵、兽首图腾 | 熔岩烈焰、燃烧余烬、黑烟 | 毁灭 |
| 阴阳/幻系 | 太极两仪、九宫格 | 微尘迷雾、虚实幻影、引力波动 | 虚无缥缈 |
| 魂系 | 九宫格锁魂纹 | 噬魂漩涡、残魂虚影、黑雾 | 阴森压迫 |
| 冰系 | 六芒寒冰阵 | 冰棱穿刺、冰晶碎片、寒霜雾霭 | 极寒肃杀 |

## 五、与本仓库其他知识文档的关系

- 与 `image_prompt_guide.md` 的扩写公式(`[主体] + [构图] + [光影] + [风格] + [画质]`)
  兼容:法术特效属于该公式里"构图与主体"之后追加的**特效层**,不替代整体结构。
- 与 `lighting_prompt_guide.md` 的"特效创意光影"一节呼应:丁达尔光/轮廓光是仙侠
  法术类镜头的高频光影关键词,两份文档配合使用。
- 涉及角色施法动作的分镜(`action` 字段),可结合 `camera_movement_prompts.md`
  的"手部细节"运镜范例——法术特效镜头常与手部/结印特写镜头搭配出现。
