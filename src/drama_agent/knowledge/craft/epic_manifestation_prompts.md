## 一、核心视觉公式

真正让"法天象地"画面立住的,不是单纯把人物变大,而是一个可复用的构图公式:

```
渺小角色前景 + 超巨型通天法相 + 天地级场景纵深 + 单一属性核心 + 强烈尺度反差
```

**先确定一个核心法则,再围绕它设计法相、武器、场景、光效和色彩**——这样生成出来的
大招才会有角色辨识度,而不是"特效堆砌但看不出是谁的技能"。核心法则举例:剑道
(万剑归宗)、幽冥(魂系)、生命(木系复苏)、六臂金焰(近战镇压)、时间法则、
创世(开天辟地)。每种法则对应完全不同的形态、武器、场景与色彩基调——先定法则,
其余视觉元素才有依据,不要反过来先堆特效再找一个法则解释。

## 四、静图定帧到动态化的落地建议

法天象地级画面信息密度极高,直接一句"角色释放大招"很难得到稳定、有层次的
AI 视频结果。更稳的做法是先把这类图当作**关键帧/大招定帧**,再围绕以下几个阶段
分别设计镜头,而不是试图一镜生成全过程:

1. **巨型法相显现**——法相从云层/大地/裂谷中逐渐浮现或降临的过程镜。
2. **能量汇聚**——法相周身或阵眼处的能量、粒子、光效汇聚过程(可结合
   `vfx_spell_prompt_guide.md` 的五维度公式细化)。
3. **天地异变**——空间、云层、山河、光影随法相出现而发生的环境反应。
4. **角色释放技能**——回到人物本体的动作镜,与法相形成呼应(可结合
   `xianxia_combat_moves.md` 的招式分解结构写这一镜)。

按这四个阶段分镜,比单镜塞入"巨大法相+能量+异变+人物"全部信息更容易稳定生成。

## 五、与本仓库其他知识文档的关系

- 与 `vfx_spell_prompt_guide.md` 的关系:法天象地是**规格更高的特殊场景**——全片
  最高光的觉醒/终极技能/最终一击才用,常规法术/法阵镜头仍按 `vfx_spell_prompt_guide.md`
  的五维度公式(阵纹结构/能量流向/粒子细节/空间动态/氛围光影)处理,不要把每场
  打斗都升格成法天象地规格,否则终极大招登场时反而失去尺度反差的冲击力。
- 与 `xianxia_combat_moves.md` 的关系:法天象地的"渺小角色前景"部分,人物本体的
  出招动作仍可套用 `xianxia_combat_moves.md` 的招式分解结构,法相是人物技能的
  视觉放大呈现,不是取代人物动作描述。
- 与 `camera_movement_prompts.md` 的"史诗开场"运镜(超远景俯瞰→人物背影前景→
  环境铺满纵深)在构图逻辑上高度一致,可直接借用该运镜范例作为法天象地镜头的
  运镜写法基础。
