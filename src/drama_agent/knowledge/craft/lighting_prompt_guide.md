# 光影提示词合集 / Lighting Prompt Guide(video-storyboard 参考文档)

> 来源:公众号《AI漫剧出图封神｜16种高级光影提示词合集》(2026)。
> 用途:`visual_aesthetics.md` 已给出光影的理论(影调对比/同步非同步/配色法则),
> 本文件补**按题材分类、可直接复制粘贴的光影关键词**——分镜确定 `lighting`/
> `color_temp` 后,可查此表把枚举值具体化成更有画面感的措辞。

---

## 总原则:人物好不好看,一半靠人设,另一半全靠光影

同一张脸,换一种布光,氛围感、故事感直接拉开差距。

## 一、电影经典人像光(特写镜头首选)

用于对话/情绪特写镜头的基础打光,追求"专业质感"而非风格化。适配 `Lighting.NATURAL`
/`Lighting.HIGH_KEY`/`Lighting.LOW_KEY` 的具体化描述。

## 二、戏剧氛围布光(情绪 & 夜戏神器)

用于强情绪/悬疑/夜戏镜头,追求戏剧张力。对应 `Lighting.LOW_KEY`/`Lighting.SILHOUETTE`
/`Lighting.RIM_LIT`。

## 三、特效创意光影(玄幻古风氛围感)

用于仙侠/玄幻类作品的法术、灵气、仙气场景。**丁达尔光**(光线穿透雾气/云层形成
的光柱)与**轮廓光**(勾勒人物边缘的逆光)是仙侠类题材的高频关键词,建议在
`prompt_guide`(按 provider)之外额外追加。对应 `Lighting.RIM_LIT`/`Lighting.GOLDEN_HOUR`。

## 四、实景环境氛围感光(沉浸式场景镜头)

用于外景/环境交代镜头,如落叶、雪景、暮色等季节感光影。对应 `Lighting.GOLDEN_HOUR`
/`Lighting.BLUE_HOUR`/`Lighting.OVERCAST`。

## 五、使用小技巧(直接影响出图效果)

- **光影词放在提示词后半段**——放在画质、人设、场景描述之后,出图效果最稳。
  与 `image_prompt_guide.md` 的扩写公式顺序一致:`[主体] + [构图] + [光影] + [风格] + [画质]`。
- **视频动画时,烛光/灯笼光可加"光影轻微晃动"关键词**,画面更生动,避免死板的静态光斑。
- **按题材选光影基调**:
  - 虐恋/悲情剧情优先选:雪落窗边冷光、暮霭沉光。
  - 仙侠/仙气镜头优先选:轮廓光、丁达尔光、萤火流光。

## 六、与本仓库 `Lighting`/`ColorTemp` 枚举的对应关系

分镜阶段仍从固定枚举(`workflow/constants.py`)里选取合法取值,枚举值本身不可自由
发挥——这是为了保证同一场景内光影一致性可被代码收敛(`_unify_scene_light`)。
本文件的作用是给 `prompt_engineer` 翻译枚举值为具体措辞时提供**题材化的具体词汇**,
而不是引入新的取值空间:

| 题材 / 场景 | 优先选用的 Lighting 枚举 | 具体化关键词方向 |
|---|---|---|
| 仙侠/玄幻施法场景 | RIM_LIT / GOLDEN_HOUR | 丁达尔光、轮廓光、灵气流光 |
| 虐恋/悲情/离别 | BLUE_HOUR / OVERCAST | 雪落窗边冷光、暮霭沉光 |
| 悬疑/夜戏/紧张 | LOW_KEY / SILHOUETTE | 大光比阴影、逆光剪影 |
| 日常/对话 | NATURAL / HIGH_KEY | 自然环境光、明亮少影 |
