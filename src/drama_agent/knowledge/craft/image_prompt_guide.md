# 图像生成 Prompt 优化规则 / Image Prompt Optimization

把用户的粗略描述扩写成详细、可执行的图像生成 prompt。适用于素材库(人物/背景/道具/服饰参考图)与关键帧静图。

## 扩写公式

按块组织,每块都要落到画面上可见的东西:

```
[主体与任务] + [构图与视角] + [材质与光影] + [风格] + [画质] + [比例] + [约束与负面]
```

块的顺序即重要性顺序 —— 模型对开头的服从度最高,把最不能错的写在前面。

## 规则

- 具体、可视化,不要抽象:写「金色夕阳下的侧脸剪影,发丝透光」,不要「很美的画面」。
- 主体锚定:外貌/服饰/材质写具体(发色长度款式、肤色、衣着颜色款式、显著特征),便于跨图一致。
- 构图与视角:指明景别/机位(近景/半身/全身;正面/侧面/俯拍/仰拍)与构图(中心/对称/三分构图)。
- 光影必写:自然光/柔光/侧逆光/三点布光;暖调或冷调,选一个方向,别互相矛盾。
- 风格明确:写实 / 水墨 / 日漫 / 赛博朋克 等,单一风格,避免混搭冲突。
- 画质:追加「高清、细节丰富、电影质感」;人物特写可加「浅景深」。
- 竖版短剧:默认 9:16 竖版立绘,除非用户另有说明。
- 约束:素材尤其要「纯净背景 / 无文字 / 无水印」,人物立绘建议纯色或简洁背景。
- 长度:简单主体 30–50 字;标准场景 50–100 字;精细 100–200 字;超过约 300 字模型会开始忽略后段。
- 语言:按目标图像模型;豆包 Seedream 用中文即可。

## 分类专项

素材库的四类各有其"必须锁死"的要素。缺了它们,模型会自由发挥到无法复用。

### 人物(character)

用于角色四视图设定板。

- **身份锚点**先写:五官、发型、肤色、体型、显著特征。这几项是跨图一致的依据,写在最前。
- 定义视图数量与版式(四视图:正面全身 / 侧面全身 / 背面全身 / 面部特写)。
- **不同视图之间服装细节不得变化** —— 这是设定板最常见的失败:同一角色换了扣子、腰带、鞋。
  把服装作为锚点重复声明一次,而不是只在开头提一句。
- 版面拥挤时减少视图数量,不要缩小每个视图 —— 缩小会让面部细节整体丢失。
- 负面约束:无文字、无水印、无边框、纯白背景。

### 背景(background)

用于场景概念图。

- 定义视角、尺度、材质、光源、空间功能 —— 五项缺一,画面就会飘。
- **不要出现人物**:背景是给角色站进去的容器;有人物会干扰后续合成,也让同一场景无法复用。
- 概念图之外要避免不合理透视(超广角畸变、消失点冲突)。
- 明确时间与天气(白天/黄昏/夜;晴/雨/雾),它决定整场戏的光影基调。

### 道具(prop)

- 单一主体、居中、纯白背景 —— 道具要能被抠出来单独用。
- 写清材质与工艺(金属拉丝 / 磨砂塑料 / 做旧皮革)和尺度参照。
- 不带关联场景、不带手部 —— 手是模型最容易画坏的部位,且会限制后续构图。

### 服饰(costume)

- 平铺或立体挂展二选一,明确说出来。
- 面料、版型、缝线、配件细节要写;这些是造型一致性的依据。
- 不带人物 —— 有人物就变成了人像图,无法作为服装参考复用。

## 反模式(避免)

- 抽象/超级词(「很美 / 震撼 / 惊艳」):不含视觉信息 → 换成具体细节。
- 矛盾指令(「明亮 昏暗 忧郁 欢快」):只选一个光影/情绪方向。
- 多个复杂主体动作堆一起:模型会顾此失彼 → 聚焦一个主体、一个核心画面。
- 复制超长段落:模型失焦 → 蒸馏成关键视觉要素。
- 无构图/无光影:模型随机发挥 → 明确补上。
- 无约束标签:冒出文字/水印/杂乱背景 → 补「无文字 / 无水印 / 纯净背景」。
- 过度磨皮:除商业美妆外,写实人物要保留皮肤纹理;「可信的小瑕疵」比完美塑料感更真。
- 画面过于干净:纪实/生活场景需要一点杂乱(桌面的杯子、地上的线),全新全净反而假。
