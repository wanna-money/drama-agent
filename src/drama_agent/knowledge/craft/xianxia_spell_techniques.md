# 仙侠法术提示词 / Xianxia Spell Technique Prompts(video-storyboard 参考文档)

> 用途:同样是"御剑飞行",有人生成出来像游戏特效,有人却有电影大片的压迫感——
> 差别往往不在模型,而在提示词有没有把法术的**形态、力量感和环境反馈**写出来。
> 本文件按仙侠法术类型收录 24 种命名法术的提示词范例,补充
> `vfx_spell_prompt_guide.md` 的五维度公式(阵纹结构/能量流向/粒子细节/空间动态/
> 氛围光影)与 `xianxia_combat_moves.md` 的招式分解结构——那两份文档管"公式怎么用"
> 与"招式怎么分解动作",本文件管"具体到某一类法术,现成的完整提示词长什么样"。

---

## 一、法术提示词的统一结构

每条法术提示词遵循同一个句式骨架:

```
[施展动作/起手姿态] + [法术核心视觉元素的形态与颜色] + [能量/粒子扩散方式] +
[环境反馈(空气/地面/云层等随之产生的变化)] + [场景背景] + [渲染质感与画质标签]
```

24 种法术按视觉核心分为六类:召唤操控类、空间位移类、攻击毁灭类、防御禁制类、
辅助增益类、元素领域类。同类法术之间的差异主要在颜色/形态,而句式结构复用。

## 七、落到分镜/prompt 的用法

1. **先按类型定角色的法术体系**:与 `xianxia_combat_moves.md` 第七节的建议
   一致——同一角色反复施法时,法术应集中在 1-2 个类别(如主角固定用攻击毁灭类
   的剑系法术,配角固定用辅助增益类),不要每次施法都跳到不相关的类型,否则
   角色能力设定会显得混乱。
2. **法术规格与剧情节点匹配**:本文件的 24 种法术是"常规技能"规格,用于日常
   打斗与展示;若剧情推进到主角突破、终局决战,应升级到
   `epic_manifestation_prompts.md` 的"法天象地"规格,不要把常规法术和终极大招
   混用同一套视觉分量,否则终极技能登场时失去尺度反差。
3. **法术释放可拆成多镜**:参照 `epic_manifestation_prompts.md` 第四节的分阶段
   思路——法术特效信息密度较高时,可拆成"起手结印/引导动作"→"法术核心视觉
   成型"→"能量释放/环境反馈"2-3 个镜头,不必追求一镜生成全部信息。
4. **与招式类法术的选择原则**:本文件的"法术"(御剑术、九霄雷法等)与
   `xianxia_combat_moves.md` 的"招式"(紫电灵拳、月华刺等)是两套命名体系,
   前者更偏"术法/能力"(常伴随法阵、召唤、领域效果),后者更偏"具体一次
   出手的招式动作"。分镜时按角色设定选择其中一套体系,避免同一角色混用两套
   不相关的命名逻辑造成设定混乱。
