# 长镜头打戏提示词 / Long-Take Fight Choreography Prompts(video-storyboard 参考文档)

> 用途:长镜头打戏的共同做法是**用一条长提示词驱动一段 10-30 秒的连续打斗**
> (而不是逐镜头分别生成再拼接),核心难点是**全程保持人物/服装/兵器一致、
> 空间位移真实连续、动作不崩坏**。本文件给出可复用公式,补 `shot_sequence.md`
> (镜与镜的节奏)和 `xianxia_combat_moves.md`(单个招式怎么分解)之外
> **一整段长镜头怎么整体搭建**这一层。

---

## 一、核心问题:长镜头打戏最容易崩的三件事

1. **人物"漂"了**——打着打着换了张脸、换了套衣服、武器数量变了、多出一只手。
2. **位置"瞬移"了**——上一秒在雪地,下一秒直接站在完全不相关的新背景里,
   观众感觉不到"打斗把双方带到了新地方"这个真实位移过程。
3. **动作"顿"了**——用了慢动作/子弹时间/冻结帧/一击后停顿等待,观众等得出戏;
   或者反复同一套拆招(重复的三段挥砍-格挡),看起来像循环播放。

解决这三件事的思路可以合并成三条铁律(见下方"三、三条铁律"),再用统一的
公式落到提示词里。

## 二、资产锁定公式(解决"人物漂了")

不管是仙侠还是真人题材,凡涉及**多人打斗且要贯穿全程**,提示词必须显式锁定:

```
[脸部身份来源(参考图/文字描述,二选一但必须唯一)] +
[发型发色 + 是否贯穿全片不变] +
[服装/盔甲的具体样式与颜色 + "不换装"的显式声明] +
[武器数量、持握方式、位置(如"空鞘固定背后") + "不交换武器"的显式声明] +
[负面提示词里逐条否定:换脸、服装突变、武器数量变化、多手多脚、分身]
```

范例(雪地追逐,双人各持刀):
> "A,成年黑发女剑客,严格采用参考图脸部身份、高马尾、红发绳、红黑短装、长护手、
> 腿甲与黑色长靴。使用参考图中的一把弧刃长刀,首帧已出鞘,右手主握、左手可辅助;
> 空鞘固定背后…… 全片只有A、B,共三把刀。A始终一刀,B始终双刀;不换脸、不换装、
> 不交换武器、不生成分身。"

范例(校园真人打斗,单人贯穿):
> "同一张脸贯穿全片。长直浅粉色头发。始终穿着上述粉色校服,不要换成牛仔或其他衣服……
> 一致性:同一张脸、同一头浅粉长直发、同一套粉色校服。不要分身、不要多余肢体、不要穿模。"

**要点**:多人混战锁定每个人的"身份三件套"(脸/发/服),独立武器数量与持握方式;
单人贯穿戏锁定"同一张脸+同一发型+同一服装"这一句式,并在负面提示词里逐条否定
换脸/换装/分身——这句否定和正向锁定同等重要,AI 视频模型在长镜头里比短镜头更容易
中途漂移。

## 三、三条铁律(解决"位置瞬移"与"动作顿了")

### 铁律 1:空间路线必须连续,不可返回起点

打斗要**沿一条真实可走的路线推进**,不是在同一片场地里原地打。写法上先规划
一条路线(如"前方雪地→左侧巨石内缘→牌坊左门洞→古树左侧根道→门后雪坡"),
再让场景元素(巨石、牌坊、古树)随镜头推进"从前方逐渐移到侧面,再退到身后",
作为真实位移的方位参照——观众靠这些静态参照物的相对位置变化确认"打斗真的在移动",
而不是背景突然换了一张图。

破坏与战损沿路线**累积、不复原**:冰壳崩裂、木栏撞断、雪地划出连续滑沟——
这些细节反过来印证路线是连续走过的,不是剪辑拼接的。

### 铁律 2:正常时间流速,不用慢动作/子弹时间/冻结帧

负面提示词应高度一致地否定:慢动作、慢运镜、子弹时间、顿帧、冻结帧、
hit-stop、黑白冲击画。真正想要"电影感的短暂强调",落地方式是**震镜**而非慢镜:
"重击先出现明确兵器接触,再发生短促定向震镜,随后立即跟随受击方向拉开;时间不停,
人物和碎片继续运动"。轻微碰撞不震镜,只有真正的重击才震镜,否则震镜频率过高会
显得画面一直在抖。

（例外：终极大招/法天象地级别的"最高光一击"可以有极短慢镜,但要卡死时长上限,
如姜月初范例里"爆炸峰值短暂慢镜,≤0.5秒"——不是常规打斗的默认写法,常规打斗仍
按本节铁律走。此规格对应 `epic_manifestation_prompts.md`,不要把日常打斗也升格。)

### 铁律 3:动作不落地就不停,击退方必须被追击

"每次受击位移之后,追击者立即跟上,对手落地便反击,不等烟雪散尽"——一次
"重击→飞退→追击"的循环内不能有静止等待的空隙。校园打斗范例里同样是
"落地立刻踢腿、旋转"，没有停顿。判断标准:如果分镜里出现"A 击退 B 后原地站立
喘气 2 秒"，这就是需要修的空隙,应改成"A 击退 B 后立即向 B 落点追击"。

## 四、逐秒/逐镜头时间戳写法(落地到 prompt 正文)

不要笼统写"接下来是一段激烈打斗",而是**把总时长切成 3 秒左右的段,
段内逐秒写清运镜+双方动作+特效**,终极大招阶段可以精确到 0.5 秒级。
可复用的写法骨架:

```
【镜头N(起始秒—结束秒)｜这一段的一句话标题】
t=第X秒 运镜(推/拉/甩/升降/贴地/跟随) + 景别(FS全景/MS中景/CU特写) +
  A的具体动作(动词,不是状态) + B的具体反应/反击(动词) + 特效随动作产生(不是独立存在)
```

范例(雪地追逐镜头1段):
> "t=1s 运镜贴雪面极速前冲,FS全景A在左前方已经踏雪冲向右后方的B,斜劈撞上B右刀,
> B左刀立即反切,A回刀拨开继续抢进,朱红与青银刀气交错展开,雪粉从两人脚后向两侧喷出。"

**为什么按秒写比按"整段描述"更稳**:AI 视频模型需要明确的时序而非同时塞入多个
动作(与 `xianxia_combat_moves.md`"起手→身体运动→效果"的分解逻辑同源,只是这里
把颗粒度细化到了秒级、且是多角色交替动作而非单人出招)。总时长每 30-60 秒左右
应有一次"全景重新交代位置"(呼应 `shot_sequence.md` 的空间锚点规则)。

## 五、特效与实际动作绑定,不能脱离动作独立存在

"特效紧随实际刀路,不自动追踪、不变成远程大招""横斩形成宽扇面,挑斩形成上升
月牙,重劈形成厚重楔形刀光"——特效的形态由**兵器实际挥动的轨迹**决定,不是脸谱化
地"挥刀就有一道固定特效"。同一把武器不同挥法对应不同特效形态,这比
`vfx_spell_prompt_guide.md`(法阵/法术特效的五维度公式)更进一步:法术特效本身
可以是独立存在的能量效果,但**近战兵器特效必须依附于挥动轨迹**,写提示词时把
"挥砍方式"和"特效形态"绑成一句话,不要分开写成两个不相关的描述。

多种能量颜色共存时(如姜月初范例的金蓝/银白/紫),交界处"只在交点短暂混亮,
不染满整幅画面"——避免多色特效互相污染导致画面变成一片模糊光斑。

## 六、按题材调整的差异点

| 题材 | 渲染技术标签 | 特殊约束 |
|---|---|---|
| 仙侠/国漫(姜月初范例) | 电影级国风3D战斗、墨色能量特效 | 参考图只锁脸/发型/服饰,不采用图片背景;"魔将不要抢女主脸" |
| 真人写实/超能力(校园超能力范例) | 照片级真实、Hollywood超级英雄电影、电影级色彩分级、细微胶片颗粒 | "保持编舞在物理上可信且视觉上接地,避免卡通式效果" |
| 真人写实/纯身体动作(校园走廊范例) | 电影感、24帧、手持跟踪镜头 | "实拍短剧质感,不要广告模特摆拍";涉及打斗动作的平台可能判定违规,需要说明"常规武术表演"降低动作幅度以通过内容审核 |

**审核提示**:真人风格的打斗提示词比仙侠国漫更容易被生成平台判定为暴力内容而拒绝
或要求降低动作幅度(见校园走廊范例作者说明)。真人题材打戏优先考虑武术表演/舞蹈化
的动作措辞("能量像打架,也像在跳舞"),仙侠国漫因为是幻想生物/法术对抗,审核压力
相对更小。

## 七、与本仓库其他知识文档的关系

- 与 `shot_sequence.md` 的关系:本文件解决**一整段长镜头怎么内部组织**(空间路线、
  资产锁定、逐秒写法),`shot_sequence.md` 解决**镜与镜之间**的节奏/时长曲线/
  180°轴线——两者不冲突,长镜头内部仍应满足"时长有形状""每3-4镜插全景"等
  既有规则,只是"镜"在这里可能是同一条长 prompt 里的一个时间段而非独立分镜。
- 与 `xianxia_combat_moves.md` 的关系:该文件管**单个招式**怎么分解成
  "起手→身体运动→效果"三段;本文件管**整场多次交锋**怎么串成连续的空间位移
  与时间戳序列。单场长镜头打戏里的每一次交锋,动作本身仍可套用该文件的招式模板。
- 与 `vfx_spell_prompt_guide.md` 的关系:法阵/法术类特效仍按该文件的五维度公式
  (阵纹结构/能量流向/粒子细节/空间动态/氛围光影)展开;本文件补充的是**近战兵器
  特效必须与挥动轨迹绑定**这条额外约束(法术特效可独立存在,兵器特效不能)。
- 与 `epic_manifestation_prompts.md` 的关系:常规打斗的"重击震镜"与终极大招的
  "极短慢镜(≤0.5秒)+法相登场"是两种不同规格,不要混用——日常交锋走本文件的
  铁律 2(不用慢镜),只有升格到法天象地/终极一击才允许极短慢镜,且要卡时长上限。
