# 故事原文的优化与扩写 / Story Text Craft

> 来源:novel-writing-skill(去AI味 novel-deslop + 大纲防AI化)。
> 适用对象是**故事原文**(用户手写/粘贴的那段文本),不是分镜、不是成稿剧本。
> 镜头语言与节拍设计另见 story_structure.md / shot_language.md —— 那两份服务分镜,本份服务文字。

短剧原文的判据只有一条:**这段文字能不能拍**。抽象心理、总结式叙述、说教收尾在小说里只是风格问题,
在短剧里是拍不出来的东西 —— 它们最终会变成一个空镜加一句旁白。

---

## 一、优化(改写现有原文)

原文已经完整,但不好改编:节奏平、缺钩子、情绪靠形容词硬说、场景散。

### 四条元原则(顺序即优先级)

1. **改味优先,不是改错**。这不是语法纠错;要改的是"抽象"变"具体"。
2. **改最少,效果最大**。能改一个词不改一句,能删一句不重写一段。人名、地名、数字、专有名词优先保留。
3. **保留创作意图** —— 只改"怎么说",不改"说什么"。剧情、人设、情节走向一概不动,不新增原文没有的内容。
   这是最硬的一条:用户点"优化"是想让文字更可拍,不是想要另一个故事。
4. **不整段删除**。多处问题逐句改,删除总量不超过原文的 25%;删前确认不丢失钩子、伏笔、
   角色特征、情节推进。

### 六道工序

每条先判断能否直接删除(删掉不丢信息就删,会丢才改写):

**A 禁用词替换** —— 换成具体动作/细节,不能换成另一个形容词。
「眼中闪过一丝不易察觉的悲伤」→「他垂下眼」;「深吸一口气」通常直接删。

**B 句式去套路** —— 直接写后项,或改成动作呈现。见下方禁用句式表。

**C 心理描写外化**(短剧最关键的一道) —— 不可拍的内心变成可拍的行为:
「他很紧张」→「他的手在抖」;「她很愤怒」→「她一把掀翻了桌子」。

情绪四层阶梯,越靠前越具体,前三层都是镜头:

| 层 | 技法 | 例 |
|---|---|---|
| 身体反应 | 生理变化 | 「他的胃缩了一下」 |
| 微动作 | 无意识小动作 | 「她把袖口拉到手掌里捏着」 |
| 行为选择 | 做了/没做什么 | 「他转身走了，没有回头」 |
| 环境映射 | 环境暗示情绪 | 「窗外的雨下得更大了」 |

越克制越有力。不需要写「他很难过」,写「他在雨里站了很久,回家发现忘了买烟,又出门了」。

**D 节奏调整** —— 打断连续排比(留 1–2 个,删其余);段落长短交错。
短剧尺度上这一条对应的是**台词长短与场景切换的错落**,不是小说的段落排布:
最重要的那句话最短;搞笑对白越长越好(累积),深情对白越短越好(击中);
一段对话里要有"接不住"的时刻 —— 沉默也是对话。

**E 对话去腔调** —— 加口语、适当打断、**删掉解释性对话**:角色不会把自己的动机说清楚。
判据:遮住角色名,只凭对白能不能分辨是谁在说话?做不到就重写。
潜台词优于直说 —— 表面聊「你还记得那年夏天吗，蝉叫得特别吵」,实际在说「我们回不去了对吧」。

**F 结尾去升华** —— 删总结性语句,用动作/场景收尾。
出现「他知道……」「这一刻……」基本可以删。

### 禁用句式表(出现即改)

| 句式 | 错误例 | 修法 |
|---|---|---|
| 「不是A，而是B」翻转 | 他不是冷漠，而是绝望 | 直接写 B,不写 A |
| 「……，带着……」万能状语 | 他笑了一下，带着一丝嘲讽 | 删状语,换具体动作 |
| 声线反差:「声音不大，却……」/「平静无波」/「听不出情绪」 | 她声音不大，却带着不容置疑的力量 | 直接写台词内容或动作 |
| 「仿佛/犹如/宛若……一般」 | 仿佛能穿透一切一般 | 删掉或白描 |
| 「眼中闪过一丝……」/「嘴角勾起一抹……」 | 眼中闪过一丝悲伤 | 「他垂下眼」/「他嘴角一扯」 |
| 抽象总结收束:「这一刻终于明白」/「才刚刚开始」/「命运的齿轮」 | 这一刻，他终于明白了 | 回到当下可见的动作/物件/对话 |
| 预告式收尾:「他不知道的是……」/「更大的风暴即将来临」 | — | 用具体物件/事件收束 |

### 禁用词

**一律替换**(不看密度):
- 情态:仿佛、犹如、宛若、如同、一丝、一抹、些许、几分、隐约、毫无征兆、几不可闻、微不可察
- 动作:深吸一口气、不禁
- 表情:眼中闪过、嘴角勾起、眉头微皱、瞳孔微缩、指节泛白、眼神锐利、目光锐利
- 心理:心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得、心中一凛、心中涌起一股
- 判断:不容置疑、不易察觉、显而易见、毫无疑问、不可否认、前所未有
- 连接:然而、此外、与此同时、值得注意的是 —— 用场景切换/动作衔接替代

**密度超了才替换**(同一千字出现 >3 次):缓缓、微微、轻轻、淡淡、突然、陡然、骤然、猛然、瞬间、猛地

### 比喻不是一律删

| 类别 | 例 | 处理 |
|---|---|---|
| 生活/角色化 | 「像一头被抛弃的野狗」 | 贴角色视角、有信息量 → 保留 |
| 通用陈词 | 「像春风一样温暖」/「如利剑般锐利」 | 删或改具体画面 |
| 抽象命运类 | 「像命运的齿轮」 | 高风险 → 落回动作/物件/后果 |

同段落比喻标记(好像/像是/仿佛/宛如/如同/犹如)≥3 次即为堆叠,保留最有信息量的 1–2 处。
写比喻前先问:**这个角色的人生里,有什么东西长得像这种感觉?** 军人不说「心很沉」,
说「像弹药箱压在胸口,搬不动也放不下」。

### 标点

短剧台词里省略号与破折号是**表演提示**(停顿、被打断),不要机械清理。
叙述部分的无功能省略号可以收掉,对白里的保留。

## 二、扩写(把点子铺成完整故事)

原文只是一个点子或几句大纲,要铺成能拍的故事。

### 先答四个问题,答不出就不要往下写

1. **一句话概括**:这是一个关于______的故事(主题,不是情节)
2. **核心矛盾**:一个**无解的两难**选择 —— 有标准答案的矛盾撑不起戏
3. **情感目标**:观众看完应该感到______(不安/热血/心疼/释然)
4. **起点与终点**:故事从______开始,到______结束

### 铺开时的硬约束

**必须具体到可视化。不可视化的描述就是不可拍摄的描述。**

| 禁止 | 替换为 |
|---|---|
| 「主角逐渐成长为……」 | 列出具体的成长转折事件 |
| 「经历了重重考验……」 | 具体是哪几个考验 |
| 「最终战胜了……」 | 具体的对抗方式和代价 |
| 「收获了友情和爱情……」 | 具体的人物关系变化 |
| 「深刻地认识到……」 | 通过什么事件、什么细节认识到 |
| 「一系列冒险之后……」 | 每一段的具体内容 |

反例:「主角在危机中展现勇气,获得同伴认可」
正例:「暴雨夜,山洪冲毁了通往镇子的唯一一座桥。他背着受伤的同伴,踩着没过膝盖的泥水走了三个时辰。
到镇上时同伴已经昏过去,他的脚掌被石头割得血肉模糊。那人在门口看到他时,第一次没有嘲笑他。」

### 三条铁律(短篇/短剧共通)

1. **一事一议**:只讲一个核心事件,只传递一个核心感受。
2. **结尾即灵魂**:价值的八成在结尾(反转/余韵/回环)。
3. **每个字都有用**:删掉任何一段后故事仍成立,说明那段多余。

### 人物立得快的两个办法

**三层标签**:身份标签(豪门弃妇)→ 行为标签(隐忍不发)→ 核心标签(步步为营)。
短剧人物就是靠一个身份标签立住的,不需要长篇传记。

**一笔定型**(配角):一个精准细节顶一段介绍。
反常行为(自杀前化好妆穿上高跟鞋)/ 标志性台词 / 职业本能 / 日常习惯 / 物件象征。

### 情绪弧型(按占全片进度的百分比布置)

| 弧型 | 形状 | 适用 |
|---|---|---|
| V 形 | 60% 处触底,快速回升 | 复仇/重逢 |
| 倒 V 形 | 40% 处峰值,急跌 | 背叛/悲剧 |
| W 形 | 多个高峰递进 | 悬疑/多反转 |
| 阶梯递进 | 无低谷,阶梯上升 | 打脸/翻身 |
| 延迟满足 | 70% 铺垫,爆炸式结尾 | 隐忍复仇 |
| 急转 | 70% 处无预兆反转 | 恐怖/动机反转 |

百分比是位置而非字数,可等比缩放到任意时长。

### 开篇

短剧的留人在**前三秒**,不在结尾 —— 钩子必须前置。

| 模式 | 操作 |
|---|---|
| 灾变开场 | 以重大事件起手 |
| 日常撕裂 | 最日常的场景中突然出现异常 |
| 冷开场闪回 | 高潮开场,再「三天前——」 |
| 旁观者视角 | 路人目睹反常 |
| 考试/选拔 | 通过测试进入新处境 |

不要用「一个平凡的早晨」开头。第一段就要立住这个故事的气质。

### 悬念的三个通用工具

信息差三态:

```
观众知道而角色不知道 = 紧张感
角色知道而观众不知道 = 好奇心
两者都不知道         = 恐惧感
```

延迟揭示:安全环境揭示 → 理性接受(效果一般);危机时刻揭示 → 来不及消化(翻倍);
来不及挽回时揭示 → "已经太晚了"(最大化)。

伏笔:小说讲三次法则,短剧压成两次 —— 先无意带过,后在关键时刻揭穿。

### 设定不要解释,要演出来

短剧没有旁白预算。

| 设定集式(禁止) | 叙事式 |
|---|---|
| 「这个世界的修炼分为练气、筑基……」 | 师兄晨练时随口说「你连练气三层都没到」 |
| 「魔法的代价是消耗精神力」 | 她施完法后鼻血直流,一个字都说不出来 |

每条设定都要有一个"展示事件"。**找不到展示事件的设定,根本不需要出现。**

## 三、自检三问(改完/写完都要过)

1. 删掉这一段,观众会错过什么?(答"什么都不会错过"= 这段是水)
2. 这一段里哪个人物发生了变化?(认知/情感/处境,至少一个)
3. 结尾比开头多了什么?(信息/紧张感/期待感,要有净增量)
