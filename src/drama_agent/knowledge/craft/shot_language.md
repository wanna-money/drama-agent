# 镜头语言 / Shot Language(video-storyboard 参考文档)

> 来源:《分镜头脚本设计教程》(Giuseppe Cristiano)+《影视分镜头设计与应用》+《以眼说话》。
> 用途:为分镜表的每个镜头补齐 **景别 / 角度 / 运镜 / 转场 / 构图** 五组字段。这些术语在 `video-prompt` 阶段会直接翻译成提示词。
> 术语中英对照取自《分镜头脚本设计教程》pp.185-189 专业词典。

---

## 总原则:分镜关注"流畅性",不是"画质"

分镜脚本"关注的不是画面质量,而是**场景的流畅性,以及如何用镜头表现场景**"。落到 AI 视频:

- 单镜画质由模型决定;**你能控制的是镜头组合与衔接**。
- 连贯性必须靠**显式声明**维系——AI 逐镜独立生成,不会记得上一镜的朝向、光线、视线高度。
- **希区柯克原则**:没有精确的提前脚本,不开机。→ 没有分镜表,不要开始烧生成额度。

## 一、景别(Shot Size)

景别 = 摄影机与被摄对象的距离,决定画面上形象的大小。**远→近 = 环境→情绪**。

| 景别 | 英文/缩写 | 定义 | 情绪/叙事功能 | 何时用 |
|---|---|---|---|---|
| 交待镜头/主镜头 | Master / Establishing (ES) | 显示场景所有内容:角色 + 环境 | 建立时空与人物关系 | **每个新场景/新地点的第一镜**;交待白天/夜晚、季节 |
| 大远景 | Extreme Long Shot (ELS) | 从很远拍辽阔场景 | 渺小感、史诗感 | 开篇气势、环境压迫 |
| 远景 | Long Shot (LS) | 远距离拍摄 | 风景如画卷、人物孤立于环境 | 风景交待 |
| 全景 | Full Shot (FS) | 人物全身或场景全貌 | 完整肢体表演可见 | 展示动作全貌、服装、姿态 |
| 中景 | Medium Shot (MS) | 人物臀部以上 | 看清角色**及周边环境** | 对话、日常动作;**宽→特写必经过渡** |
| 中特写 | Medium Close-Up (MCU) | 肩部或胸部以上 | 介于环境与情绪之间 | 台词、表情初显 |
| 特写 | Close-Up (CU) | 被摄对象充满画面 | **走入内心的亲近感**,排除其他一切 | 表达内心情绪、单人反应 |
| 大特写 | Extreme Close-Up (ECU) | 某个细节充满画面 | 极度聚焦、悬念、细节揭示 | 纸上的字、关键道具、一句特殊台词 |
| 过肩镜头 | Over-the-Shoulder (OTS) | 隔着一人肩膀拍另一人 | 对话中的主客关系 | **对话戏成对生成**(正反打) |
| 双人镜头 | Two Shot | 两个角色的中景 | 关系并置 | 宽→特写之间的过渡 |

**景别递进铁律**:
- 每个新地点第一镜 = **交待镜头**(剧本里不会写,是分镜师的分内工作,AI 视频里要主动加)。
- 递进走 **宽 → 中 → 特写**,**禁止宽→特写直跳**,中间用中景过渡。
- 要**速度/紧张** = 一组紧凑特写(手部、仪表、局部)快切。对 AI 视频友好:特写画面小,模型更容易画好,避免大范围运动的形变。
- **特写/近景省着用**,只在需要强调情绪的一刻用。滥用特写会丢失环境与叙事。

## 二、摄像角度(Camera Angle)

角度是**权力关系的编码**。写镜头前先问:这个镜头里谁占上位?

| 角度 | 英文 | 含义 | 何时用 |
|---|---|---|---|
| 平视 | Eye Level | 中性、代入,"把观众放进角色中" | 默认基准 |
| 仰视/低角度 | Low Angle (LA) | **权威、力量、优势;也表威胁** | **角色登场镜头**(彰显地位) |
| 俯视/高角度 | High Angle (HA) | **弱势、恐惧;强调孤独** | 角色被压制;旁观者/监控视点 |
| 鸟瞰/顶部 | Bird's Eye / Top Shot | 上帝视角、抽离、命运感 | 描述性镜头;**必须配反向角度回应** |
| 蠕虫镜头 | Worm's Eye | 极低角度向上,极度压迫 | 强烈威胁感 |
| 地面镜头 | Ground Shot | 平放地面,与地平线一致 | **让观众期待某物入画**(小巷/走廊纵深) |
| 荷兰角 | Dutch / Canted | 水平线倾斜,失衡不安 | 悬疑、险境、精神紧张 |
| 反转角度 | Reverse Angle | 约 180° 反转 | 过肩镜头的成对回应 |
| 主观视点 | POV / Subjective | 角色所见 | 把客观镜头与主观镜头焊接 |

**角度配对铁律**:高低角度"经常联系在一起";用了极端角度(鸟瞰/蠕虫)**必须配一个反向角度回应**,否则观众失去空间参照。
**视点揭示技巧**:让鸟瞰镜头成为某角色的主观视点,下一镜揭示这个人——两镜自动咬合(AI 多镜头连贯性的救命技巧)。

## 三、摄像机运动(Camera Movement)

运镜的目的是**引导注意力、让观众沉浸**——不要为炫技加运镜。每个运镜都要能回答"它服务于什么注意力引导",否则改固定镜头。

| 运镜 | 英文 | 定义 | 功能 |
|---|---|---|---|
| 摇摄 | Pan | 机位不动,水平转动镜头轴线 | **交待场景和位置**(最常见) |
| 垂直摇 | Tilt | 上下摇动 | 显示高度、打量物体 |
| 移动/推拉 | Dolly | 摄影机在轨道/平台上移动 | 精确平移、推近拉远 |
| 跟随 | Tracking / Follow | 跟随主体移动 | 伴随、紧盯 |
| 升降 | Crane / Jib | 摄影机上下移动 | 宽阔全景、升降揭示 |
| 稳机 | Steadicam | 机架绑身,平滑 | 流畅穿行(库布里克《闪灵》) |
| 手持 | Hand-held | 手持,摇摆不稳 | **纪实风格**、慌乱、临场 |
| 固定 | Static | 机位不动 | 稳定、克制、观察 |
| 缩放 | Zoom | 改变焦距(非移动机位) | 强调细节;可快可慢 |
| 变焦点 | Rack Focus | 焦点在前后景间转移 | 注意力转移、关系揭示 |
| 眩晕效果 | Dolly Zoom | 边推近边后退,主体大小不变而透视变 | 混乱、惊奇、震惊 |
| 快速摇 | Whip Pan | 极快横摇 | 急促转场 |
| 长镜头 | Long Take | 持续时间长 | 连续、真实、张力累积 |

**运镜的 AI 视频铁律**:
- **一镜只一个运镜**。混合"变焦+摇+移动+升降"是新手标志(《电影剧本写作基础》原文斥责),也是 AI 生成不稳定的头号原因。
- **写明方向**(左→右 / 推近 / 拉远),等价于分镜脚本上的箭头。
- 需精确物理联动的运镜(眩晕效果、快速摇、复合运镜),模型难稳定复现——要么描述**视觉结果**("背景透视急剧压缩而主体大小不变"),要么拆成两镜,要么改用更稳的替代。
- 不确定用什么运镜时,统一降级为 **"运动镜头 + 主体 + 方向"** 兜底。

**视觉强度排序**(《以眼说话》):变焦 < 左右摇 < 上下摇 < 平移/升降 < 广角推拉(最强)。二维运动(摇/变焦)强度低,三维运动(平移/推拉/升降)强度高。

## 四、转场与镜头连接(Transition & Cut)

**这是 AI 多镜头视频最缺的一环**——最大痛点是镜头间跳跃生硬。

| 转场 | 英文 | 定义 | 何时用 |
|---|---|---|---|
| 硬切 | Cut | 直接切换 | **时空跨度大时(黑夜→白天、内→外)直接硬切,不必加特效** |
| 淡入淡出/叠化 | Fade / Dissolve | 逐渐消失/出现 | 段落终结、时间流逝 |
| 划像 | Wipe | 新场景推出旧场景 | 明快分隔 |
| **关联剪辑** | **Match Cut** | 两场景共享相同/相似/相关元素 | **掩盖时空跳跃的头号武器** |
| 跳接 | Jump Cut | 同一动作不连续片段快排 | 表现紧张、焦躁、匆忙;压缩时间 |
| 旁跳/插入 | Insert / Cutaway | 主动作外的细节镜头 | **衔接不上/有瑕疵时插一个细节特写掩盖过去** |
| 蒙太奇 | Montage | 一串无台词短镜头组接 | **表现时间流逝/过程,无需台词——AI 视频极友好** |
| 交叉剪辑 | Crosscutting | 两条线交替 | 悬念、平行、命运交织 |
| 分画面 | Split Screen | 同屏多画面 | 同步展示(如打电话两人) |
| 画外音 | Off Camera (OC) | 画面外的声音 | **可替代画面,省一个镜头**(如门铃) |

**转场的 AI 视频关键用法**:
1. **少切换原则**:能一个运镜完成的,不要拆两个镜头(每次切换都是一次一致性风险)。
2. **跳跃太大 → 关联剪辑**:让镜头A结尾与镜头B开头共享形态相似的元素(圆→圆、水→水、表→钟)。
3. **镜头衔接不上/有瑕疵 → 旁跳细节特写**掩盖("掩人耳目、蒙混过关"的现代版)。
4. **要表现"过了很久/成长/准备过程" → 蒙太奇**:4-5 个无台词短镜头,景别角度有变化,共享统一光色,靠视觉一致性而非空间连续性维系,用递进(白天→黄昏、清爽→汗湿)表现时间。

## 五、构图与连续性规则(Composition & Continuity)

### 轴线 / 180° 准则(AI 多镜头最容易出错、最少被提及)

- **运动线(轴线)**:穿过两个对话人物的假想线。摄影机应停在线的**一边**,否则**跳轴**——人物朝向翻转,"两人都朝同一边看"或突然对调位置。
- **AI 视频对策**:对话/对峙场景,**在每一条提示词里固定屏幕方向**:「男人始终位于画面左侧、面朝右;女人始终位于画面右侧、面朝左」,每镜重申。禁止相邻镜头来回翻转机位。
- 若剧情需跨到另一侧:插入一个展示摄影机绕行过程的运动镜头(环绕/弧形),之后所有镜头停在新的一侧。

### 视线高度一致(与跳轴并列的隐形杀手)

同一场对话戏,角色视线高度必须一致。"如果视线高度一直在变化,谈话就很难继续下去了。" → 提示词写明"两人视线水平齐平,均处于画面上三分之一处"。

### 朝向留白(Nose Room / Looking Room)

为角色面朝的方向留出适当空间。空白处暗示画外角色的存在,并将观众视线引向那个方向——既平衡构图又省一个镜头。

### 安全镜头(Safe Shots)——AI 视频尤其重要

模型在**典型镜头模式**上训练最充分、最稳定;炫技镜头 = 高失败率。
**对话场景的安全镜头组合** = 带透视的特写 + 双人镜头 + 过肩镜头。直接作为 AI 对话戏的默认分镜模板。

### 失衡构图(有意为之)

主体极度偏置、地平线倾斜 → 制造不安/不适,是有意的情绪工具。

## 六、情绪 → 镜头完整对照表

综合《分镜头脚本设计教程》第22、23、26课:

| 想表达 | 景别 | 角度 | 构图/运镜 |
|---|---|---|---|
| 角色地位高 / 登场 | 中景或全景 | **低角度仰视** | 置于画面上方 |
| 弱势 / 恐惧 / 孤独 | 全景或中景 | **高角度俯视** | 大量留白包围 |
| 内心情绪 / 亲近 | **脸部特写** | 平视 | 排除其他一切 |
| 关键细节 / 文字 | **大特写 ECU** | — | 满画面 |
| 紧张 / 速度 | **一组紧凑特写** | — | 快切 |
| 不安 / 失衡 / 险境 | 任意 | **荷兰角** | 有意失衡 |
| 混乱 / 震惊 | 中景~特写 | 平视 | **眩晕效果** |
| 期待某物入画 | 全景 | **地面镜头** | 纵深空间(小巷/走廊) |
| 抽离 / 命运感 | 大远景 | **鸟瞰** | 必配反向回应 |
| 压抑 / 无路可退 | 特写 | — | **紧凑取景** |
| 自由 / 疏离 | 全景~远景 | — | **松散取景** |
| 真实 / 慌乱 / 临场 | 任意 | — | **手持**(纪实) |
| 沉稳 / 观察 / 温暖 | 中景 | 平视 | **固定镜头** |
| 机械感 / 高科技 | 特写~细节 | — | **慢镜头** |
| 时间流逝 / 过程 | 混合景别 | 变化 | **蒙太奇**(无台词) |
| 陷入回忆 | 落在**特写** | — | 特写后切闪回,声音提前叠化 |

## 七、常用镜头组合句式(《影视分镜头设计与应用》)

这些"自动咬合"的镜头组合,对 AI 视频跨镜连贯性极有价值:

| 组合 | 做法 | 用途 |
|---|---|---|
| **正反打** | 过肩镜头 + 反转镜头成对,严守180° | 对话戏标准语法 |
| **主观/客观切换** | 客观镜头 → 该角色 POV → 揭示他在看什么 | 把两个镜头用视点逻辑焊接 |
| **高低角度配对** | 角色进门用低角度 → 紧接纵观全场的高角度 | 双镜最小叙事单元 |
| **镜头组** | 同一主体完整动作的分解(如开车:全景→换挡手部特写→仪表特写) | 制造速度/紧张 |
| **蒙太奇句型** | 前进式/后退式/复合式/穿插式 | 镜序模板 |
| **动作与反动作** | 一个动作镜头 + 一个反应镜头配对 | 对话/冲突场景 |

**库里肖夫效应(核心杠杆)**:同一个画面 + 不同的下一镜 = 完全不同的含义。这意味着 AI 多镜头视频的**意义产生于镜序**,而非单镜——排列顺序本身就是创作。

## 八、分镜脚本标准格式(单镜必填字段)

综合《分镜头脚本设计教程》第5单元 + 各注释规范,一个镜头的完整字段:

```
镜号 | 时长 | 内/外·地点·时间 | 景别 | 角度 | 屏幕方向 | 运镜(+方向) | 画面动作(一镜一动作) | 音效 | 与上镜切换 | 注释
```

**两层输出模型**(《分镜头脚本设计教程》客户脚本 vs 拍摄脚本):
- **L1 创意概述层**(给人看):整体基调、风格、色调,少量关键画面——"上色"。
- **L2 逐镜头技术层**(给模型看):景别、角度、运镜、连续性——精确但不堆砌形容词。

> 原则:"表意即可,无须着过多笔墨。" 提示词堆砌形容词反而降低可控性,**精确 > 华丽**。
