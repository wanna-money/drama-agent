# 镜头序列与节奏 / Shot Sequence & Rhythm(video-storyboard 参考文档)

> 来源:猫叔《镜头序列 Skill 合集》(WaytoAGI)+ 经典动作片剪辑语法(《谍影重重》《疯狂的麦克斯》)
> + 蒙太奇理论(爱森斯坦、库里肖夫)。
> 用途:决定**一段戏由哪些镜头按什么时长排列**。`shot_language.md` 管单镜的景别/角度/运镜,
> 本文件管镜与镜之间的**节奏与因果**。

---

## 总原则:PPT 感来自"等长 + 静止 + 孤立"

AI 视频最常见的失败是"动态 PPT":每镜一样长、每镜都不动、每镜各说一句。三个病因:

| 病因 | 表现 | 解法 |
|---|---|---|
| **等长** | 所有镜头同一时长 | 按序列角色分配时长(见下方各模板) |
| **静止** | 运镜全是 static | 每镜都要有**镜内运动**:主体动作、运镜、或环境动势 |
| **孤立** | 每镜独立描述一个状态 | 相邻镜必须有**因果或视线连接**(动作-反应、视点揭示) |

> 判据:把分镜表的时长列念一遍,如果是"5,5,5,5,5…",这段戏一定是 PPT。

**镜内运动的三个层次**(至少满足一个,理想是叠加):
1. **主体动作**——人在做一个有起止的动作(不是"站着"、"看着")
2. **运镜**——推/拉/摇/移/跟,哪怕轻微
3. **环境动势**——风雪、烟尘、火光、水波、飘落物

## 一、时长即节奏(最重要的一节)

时长不是"这个画面需要多久看清",而是**情绪强度的表达**。强度越高,镜头越短。

| 强度 | 时长 | 用在哪 |
|---|---|---|
| 建立/交代 | 3-5s | 场景开场、空镜、远景交代空间 |
| 常规叙事 | 2-4s | 对话、行走、日常动作 |
| 紧张递进 | 1-2s | 蓄力、逼近、决定前的一瞬 |
| 冲击/爆发 | **0.3-0.8s** | 击中、爆炸、惊吓、反转揭示 |
| 情绪停留 | 4-8s | 悲伤、离别、结尾定格 |

**节奏曲线**:一段戏的时长序列应当有形状,不是平的。
- 动作戏:**长 → 短 → 极短 → 中**(建立 → 蓄力 → 击中 → 反应)
- 情感戏:**中 → 长 → 极长**(渐入,给情绪时间发酵)
- 悬疑:**长 → 渐短 → 极短 → 长**(铺垫 → 逼近 → 惊吓 → 余韵)

⚠️ AI 视频模型通常有最短时长限制(如 3-5s)。**做不到 0.3s 时的替代方案**:
- 该短的镜头取模型允许的最短值,并在 prompt 里写"动作在前 0.5 秒内完成,随后画面静止/烟尘弥漫";
- 或把"击中"与"反应"合并成一镜(击中 + 跌出),用镜内动作节奏代替剪辑节奏。
- **不要**因为做不到就给它 5 秒——那正是冲击力消失的地方。

## 二、动作戏序列(打斗/追逐/爆破)

### 标准打斗序列(1v1 一次交手)

| 序 | 角色 | 景别 | 时长 | 内容 | 运镜 |
|---|---|---|---|---|---|
| 1 | Setup | Wide/LS | 2-3s | 建立空间关系:双方位置、距离、地形 | static 或缓慢横移 |
| 2 | Attack_Prep | Medium | 0.5-1s | 攻击者蓄力(抬手、沉肩、脚下发力) | 轻微推近 |
| 3 | Attack_Execution | Close/Medium | 0.3-0.5s | 攻击动作本身 | 轻微跟随 |
| 4 | Impact | Close | 0.3-0.5s | 击中瞬间(身体反应、飞溅、变形) | 手持晃动 |
| 5 | Reaction | Medium/Close | 1-2s | 被击者反应 + 攻击者状态 | static |

**一次交手 = 5 镜、总长 4.5-7s**。三次交手递进即一段完整打斗。

### 空间定位规则(动作戏最容易崩的地方)

- **严守 180° 轴线**:双方连线不可跨越,否则观众瞬间失去方位感。
- **每 3-4 镜插入一个 Wide** 重新交代位置("空间锚点"),否则连续特写会让人不知谁在哪。
- **屏幕方向一致**:A 始终从左攻向右,B 反之。方向一变即视为新的一次交手。

### 追逐序列

`前方视角(被追者)→ 后方视角(追者)→ 侧向跟拍(速度感)→ 障碍/转折 → 距离变化`

速度感来自**参照物快速掠过**,不是主体动得快:近景前景物(树、栏杆、行人)横向划过画面。

### 爆破序列(时间轴设计)

`预兆(0.5s 静默)→ 爆发核心(0.3s 极短)→ 冲击波扩散(0.5s)→ 碎片飞散(1s 可慢镜)→ 幸存者反应(2s)`

## 三、对话戏序列

### 正反打(Shot / Reverse Shot)

标准语法:`过肩 A(听) → 反打 B(说) → 过肩 B(听) → 反打 A(说)`,严守 180°。

**呼吸感**:不要句句都切。
- 一方长台词时,**在对方的反应上停留**(听比说更有信息量);
- 关键台词前给 0.5-1s 静默(停顿即重音);
- 情绪转折处切到更近的景别(MS → CU → ECU 逐层推进)。

### 反应链(Reaction Chain)

一句关键台词后,依次给出各人反应:`说话者 → 主要听者 → 次要听者 → 回到说话者`。
反应镜头**必须有微表情或小动作**(眼神移动、手指收紧、呼吸变化),否则就是静态肖像。

### 过肩镜头(Over the Shoulder)

前景放对方肩/后脑的虚化剪影 → 制造"在场感"与景深。纯正面对切会显得像证件照轮播。

## 四、情感戏序列

### 悲伤/离别

`环境空镜(交代氛围)→ 人物全景(孤立于环境)→ 中景(身体语言)→ 特写(面部)→ 手部/细节特写 → 空镜收尾`

时长**逐镜变长**,给情绪发酵时间。结尾空镜可长至 6-8s。

### 关键原则

- **不要正面拍哭**:侧脸、背影、手部、被遮挡的脸更有力量。
- **让环境替人物说话**:雨、雪、落叶、熄灭的灯、空掉的座位。
- **动作停顿**:情绪最强处让人物静止 1-2s,周围仍有动势(风、雪),形成"内静外动"。

## 五、悬疑/惊悚序列

### 紧张感营造

`正常状态(长镜 4-5s)→ 异常细节(中景 2-3s)→ 主观视点探索(1-2s 逐次缩短)→ 极短爆发(0.3s)→ 余韵(3-4s)`

时长**单调递减**到爆发点,是紧张感的机械来源——观众不知道为什么紧张,但节奏在压迫他。

### 技巧

- **信息差**:观众知道而角色不知道(希区柯克式悬念),靠**空间外的镜头**建立(门缝后的影子)。
- **画外空间**:把威胁放在画框外,只给声音与反应。
- **Jump Scare 前必须有静默**:骤然安静 0.5-1s,再爆发。

## 六、转场与蒙太奇

### 匹配剪辑(Match Cut)——最不生硬的转场

在相邻两镜之间找一个**共同元素**衔接:

| 匹配类型 | 做法 | 例 |
|---|---|---|
| 形状匹配 | 前镜结尾的形状 ≈ 后镜开头的形状 | 圆形井盖 → 满月 |
| 动作匹配 | 相同方向/速度的动作接续 | 挥剑下劈 → 斧头落下 |
| 颜色匹配 | 主色调延续 | 红灯 → 血 |
| 声音匹配 | 音效跨镜延续 | 尖叫 → 汽笛 |

### 时间压缩蒙太奇(最容易变 PPT 的地方)

**病因**:把"过程"拍成一系列静态结果照。

**解法**:
- 每个片段都要有**未完成的动作**(正在挥剑、正在爬,不是"挥完了"、"爬上去了");
- 片段之间用**同一动作的不同阶段**衔接(动作匹配),而非跳到无关画面;
- 时长**递减**(5s → 3s → 2s → 1s)营造加速感;
- 结尾一个**长镜**收束(展示最终状态),形成"加速后停顿"。

### 场景切换(跨场景硬切最容易割裂)

同一场景内硬切是正常剪辑语法;**跨场景**(时间/地点变了)需要额外处理:
- 前一场用**出画**收尾(人物走出画框、镜头摇向空处、光线渐暗);
- 后一场用**入画**开场(空镜起 → 人物进入,或从细节推开);
- 或用匹配剪辑焊接两场。

## 七、给分镜生成的硬约束(自查清单)

产出分镜表后逐条核对:

1. **时长不得全部相同** —— 同一场戏至少有 3 种不同时长。
2. **static 占比 ≤ 1/3** —— 其余镜头必须有运镜或明确的镜内运动。
3. **每镜描述必须含一个动词** —— "站在崖边"不合格,"雪风掀起衣袍、他握紧断剑"合格。
4. **相邻镜有连接** —— 动作-反应、视线-对象、或匹配元素;不可两镜各说一事。
5. **动作段落遵循节奏曲线** —— 建立(长)→ 蓄力(中)→ 冲击(最短)→ 反应(中)。
6. **每 3-4 个近景插一个全景** —— 空间锚点,防止观众失去方位。
7. **跨场景处有出画/入画或匹配** —— 不可裸接。
8. **结尾镜给足停留** —— 4-8s,不要和中间镜一样长。
