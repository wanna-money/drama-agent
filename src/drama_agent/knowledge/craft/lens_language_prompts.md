# 镜头参数与视觉身份 / Lens & Visual-Identity Prompts(video-storyboard 参考文档)

> 来源:公众号《AI 画面有没有电影感,关键不在多写几个形容词》(2026)。
> 用途:`shot_language.md` 已覆盖景别/角度/运镜/转场/构图五组字段,但缺**摄影参数**
> (景深/焦段/快门)与**视觉身份**(画风/世界观/调性)两层。只写"电影感、大片质感、
> 8K、超高清"这类抽象形容词,模型不知道你想要的是浅景深压迫还是长焦压缩,结果是
> 随机抽出来的壁纸而非有意图的镜头。本文件补这两层,与 `shot_language.md` 配合使用。

---

## 一、电影感是一组选择,不是一句形容词

一张画面的"电影感"可以拆成三层,提示词必须逐层落实,不能只写第三层:

1. **摄影参数**(景深/焦段/快门):决定画面像用什么镜头拍,空间怎样展开,动作是
   凝固还是拖影。
2. **镜头表达**(机位/景别):由 `shot_language.md` 覆盖,决定观众站在哪里看、
   看什么。
3. **视觉设定**(画风/世界观/调性):决定作品属于什么世界,整组画面是否像同一部片。

新手最容易犯的错是第三层写了一堆("东方美学、史诗、电影感"),第一层完全空着——
没有明确景深/焦段/快门,模型只能替你做导演决定,结果不可控。

## 二、摄影参数:景深、焦段、快门

### 1. 景深(Depth of Field)——决定观众先看哪里

景深不只是"背景虚化",真正控制的是观众的注意力分配。

- **深景深**(如 f/16):人物和环境都清楚,适合交代世界、空间关系、场面信息。
- **浅景深**(如 f/1.4~f/2.8):人物清楚、背景模糊,适合突出眼神、情绪、关键物体。

写 Prompt 时不要只扔一个光圈数值,模型未必严格模拟光学,要把参数和视觉结果一起写:
"85mm 人像镜头,f/2.8,浅景深,人物面部与眼睛清晰,背景山林柔和虚化,焦点牢牢落在
人物情绪上。" 想交代环境用"深景深、前中后景都清晰";想突出人物用"浅景深、背景
柔化、眼神精准对焦"。

### 2. 焦段(Focal Length)——决定空间看起来有多远

焦段不是景别。焦段改变的是视角范围、透视关系和背景压缩感,与景别(截取范围)
是两个独立维度,不要混为一谈:

| 焦段 | 效果 | 适用 |
|---|---|---|
| 14mm / 24mm(广角) | 装下更多环境,近处显得更大,空间冲击力强 | 环境参与叙事、纵深展示 |
| 50mm | 接近自然观看感 | 中性叙事镜头 |
| 85mm | 适合人物 | 人像、对话、情绪镜头 |
| 200mm(长焦) | 压缩空间,远处背景像被拉到人物身后 | 把人从环境里剥离、强调孤立感 |

选择口诀:**想让环境参与叙事用广角,想把人从环境里剥离出来用中长焦**。范例:
"24mm 广角镜头,女性侠客位于雨后竹林石阶,前景石块略有夸张,纵深明显,环境占据
画面大部分,人物与世界的关系清楚。" 若模型对具体数字反应不稳定,补上"广阔视角、
前景夸张、纵深明显"或"长焦压缩、背景靠近、人物突出"这类结果描述兜底。

### 3. 快门(Shutter Speed)——决定动作是清楚还是有速度

快门速度决定动作在单帧里被记录成什么样:高速快门凝固水滴、头发、剑刃;慢速快门
留下拖影,画面更有速度感。**动作画面不是越清楚越好**:招式展示/商品细节/关键定格
适合高速快门;追逐/挥剑/奔跑想强调速度时,保留少量运动模糊反而更对。范例:
"女性侠客在雨中快速挥剑,中景,1/500s 高速快门,剑刃、雨滴与飞散落叶清晰凝固,
动作方向明确,紧张的武侠电影瞬间。" AI 视频 Prompt 里可以把数字换成更直接的运动
语言,如"动作清晰、极少拖影"或"自然运动模糊、剑光形成短促弧线"。

## 三、视觉身份:画风、世界观、调性

这三项要在**角色设定阶段就固定**,并在同一部作品/同一集里保持统一——不能第一镜
真人写实、第二镜突然变成游戏 CG、第三镜又成手绘动画。

### 4. 画风(Art Style)——决定用什么视觉语言呈现

真人写实、细节 CG、3D 动画、2D 动画不只是清晰度不同,会改变材质、轮廓、光影和
观众预期。范例:"真人写实武侠电影风格,真实皮肤纹理与湿润布料,克制的数字增强,
拒绝塑料皮肤、游戏立绘感和过度锐化。"

### 5. 世界观(World-building)——决定人物生活在什么规则里

世界观不是给背景换一张皮,而是设定建筑、交通、能源、服装、道具、社会规则如何
共同成立。同一个角色放进不同世界观,故事会自然长出完全不同的冲突。写世界观时
**少堆"宏大、史诗、震撼",多写可见元素**:建筑材料、能源方式、天气、交通工具、
城市密度,以及旧时代元素怎样与新技术共存。范例(赛博长安):"唐风屋檐与高层
未来都市叠合,汉字霓虹、全息投影、雨夜石板路、机械巡逻装置;传统佩剑与电子
护腕同时存在。"

### 6. 调性(Tone)——决定整部作品给人的总体感受

调性是色彩、光线、材质、构图、节奏共同形成的情绪方向,比"风格高级"更具体,
也更适合保持一组作品的统一。范例(雨夜霓虹):"雨夜港风调性,冷蓝环境光与暖橙
霓虹形成互补,湿地反射,高反差但保留暗部层次,空气中有细雨和薄雾,克制的胶片
颗粒。"柔粉对称构图显得雅致克制;低饱和粗颗粒废墟材质产生暴烈张力;明亮自然
适合幻想冒险;冷蓝暖橙霓虹适合雨夜都市——先确定这一集/这一场戏要哪种情绪方向,
再选调性关键词,不要把互斥的情绪词堆在一起(如"明亮 昏暗 忧郁 欢快"同时出现)。

## 四、完整镜头 Prompt 的组织顺序

把以上各维度串起来,得到一条稳定的结构(与 `shot_language.md` 的"景别→运镜→
主体动作/场景/光线"顺序一致,焦段/景深/快门插入运镜与主体动作之间):

```
主体与动作 + 场景与世界观 + 景别 + 机位 + 焦段 + 光圈/景深 + 快门/动作质感 +
光影 + 画风 + 调性 + 画幅
```

完整范例:"一位成年中国女性侠客,黑色高马尾,穿深靛蓝古风轻甲,雨后站在山中
古寺石阶上,听到身后动静后警觉回头,右手靠近剑柄。人物近景,低机位轻微仰拍,
85mm 中长焦镜头,f/2.8 浅景深,人物眼睛精准对焦,背景古寺和山雾柔和虚化;
1/500s 高速快门,雨滴和发丝清晰。冷灰天光从侧后方勾勒轮廓,湿润石板反射微弱
暖灯;真人写实武侠电影风格,真实皮肤与布料纹理,冷蓝与暖橙的克制对比,低饱和,
轻微胶片颗粒,16:9。"

## 五、调参练习方法(适用于人工核对提示词效果,不进入自动化 prompt 生成流程)

固定角色、场景和动作,每次只改一个参数(先换景别,再换机位,再换焦段),把对照图
排在一起观察每个词真正控制了什么。这是提示词调参的方法论,不是每次生成都要执行
的步骤——写分镜提示词时,应直接按第四节的顺序一次性把各维度写全,不必逐参数
试错。

## 六、与 `shot_language.md` 的分工

- `shot_language.md` 负责**景别 / 角度 / 运镜 / 转场 / 构图**,是分镜表每个镜头
  必填的五组字段,决定"镜头怎么切、怎么动、怎么组接"。
- 本文件负责**景深 / 焦段 / 快门**(摄影参数)与**画风 / 世界观 / 调性**(视觉身份),
  是对单镜"拍摄质感"的补充规格,以及对整部作品"视觉统一性"的约束。
- 两者不重叠、互为补充:分镜阶段先用 `shot_language.md` 定好景别与运镜,再用本
  文件的摄影参数把这一镜的"电影感"具体化,视觉身份三项则应在项目/集级别一次性
  定好,不需要每镜重复设计,只需在每镜提示词里保持措辞一致。
