# 仙侠招式提示词 / Xianxia Combat Move Prompts(video-storyboard 参考文档)

> 来源:公众号《4组漫剧仙侠打斗大招(附提示词指令)》《AI漫剧打斗动作提示词分享》(2026)。
> 用途:仙侠/玄幻类短剧的打斗镜头常见失败是"法术特效糊成一团、人物动作僵硬、
> 出招镜头重复"。本文件按兵器/招式类型给出可直接套用的命名招式模板,
> 每个招式的提示词遵循统一的**动作分解结构**,供分镜/prompt 阶段在涉及打斗招式的
> 镜头时参考。与 `vfx_spell_prompt_guide.md`(法阵/法术特效五维度公式)互补——
> 那份管"法术长什么样",本文件管"人物怎么出招、动作怎么分解成连续画面"。

## 一、招式提示词的统一结构

每个招式的提示词遵循同一个分解顺序,这个顺序本身就是可复用的公式:

```
[起手姿态/蓄力动作] + [身体部位的具体运动] + [法力/兵器的视觉表现] + [出招的最终效果]
```

例如"紫电灵拳":「双膝微屈蓄力,明眸直视前方(起手姿态)→ 拳面浮起淡紫电芒,
双臂交替快速打出(身体运动 + 法力表现)→ 拳风轻鸣,拳影连绵不断向前冲击(出招效果)」。

**这个结构比单纯写"她打出一拳,冒紫光"更好用**:AI 视频模型需要明确的动作时序
(先蓄力、再出手、再体现效果),而不是一句笼统描述里塞多个同时发生的细节。

| 寒芷绵掌 | 灰黑幽芒,阴柔 | 莲步放轻,手掌半握收拢,暗劲潜藏掌心,灰黑幽芒缓缓游走,阴柔劲力渗入 |
| 轻云扬掌 | 亮黄劲光,上扬 | 下盘稳稳立定,玉臂猛然向上扬起,掌心迸发亮黄劲光,自下而上进发 |

**共同规律**:拳掌类招式的视觉核心是**掌心/拳面的光效颜色 + 运动轨迹**(直冲/

(刚猛用直线冲击、阴柔用缓慢渗入、上扬用自下而上)。

## 七、落到分镜/prompt 的用法

1. **先定角色的招式体系再分镜**:同一角色反复打斗时,若每次出招都换一套完全
   不相关的效果(这次紫电、下次赤霞),观众会觉得角色能力设定混乱。角色应固定
   1-2 个招式体系(如某角色专精"剑法类"的月华刺+千剑影),偶尔的新招式代表
   剧情节点(突破/得到新传承)。
2. **多招连续使用时按节奏曲线排列**:参照 `shot_sequence.md` 的动作节奏曲线
   (建立→蓄力→冲击→反应),招式的"起手姿态"对应建立/蓄力镜,"出招效果"
   对应冲击镜,不要把整个招式的分解结构压进一个镜头——分镜时可以把上表每行的
   三段拆成 2-3 个镜头(蓄力镜 + 出招镜,必要时加一个效果特写)。
3. **兵器/身法类招式配合镜头景别**:兵器类的"瞄准→发射"适合近景到中景的
   镜头切换(参考 `camera_movement_prompts.md` 的"手部细节"运镜);身法类的
   瞬移/腾空适合跟随运镜(tracking)体现速度感。
4. **无法术特效的写实近战(第六节)优先用于常规打斗**:不是每场戏都需要法术
   光效——普通门派内战、凡人切磋、非修仙题材的动作戏,套用第二~五节的属性光效
   会显得突兀。先问"这场戏的角色有没有修为/法力设定",没有就走第六节的纯身体
   动作招式,视觉核心是力学过程(蓄力/发力/受力/残影),不依赖颜色光效区分招式。
