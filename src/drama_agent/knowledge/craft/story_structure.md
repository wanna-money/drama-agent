# 故事结构 / Story Structure(video-storyboard 参考文档)

> 来源:《故事》(Robert McKee)+《救猫咪》(Blake Snyder)+《电影剧本写作基础》(Syd Field)。
> 用途:把编剧的"故事结构"理论转化为"如何结构化一段有叙事张力的 AI 视频/多镜头序列"的可操作规则。
> 本文是 SKILL.md 阶段一~三的详细展开;SKILL.md 里的节拍表、+/-与><、gap引擎是本文的精简版。

---

## 一、先写一句话:概述与类型

三本书的共识:**动笔前先写一句话概述**。写不出 = 创意本身没戏,再漂亮的镜头也是浪费。

### logline 四要素(《救猫咪》)

| 要素 | 原书含义 | 映射到 AI 视频 | 自检问题 |
|---|---|---|---|
| **反讽/钩子** | 反讽 + 情感共鸣,"不得不去挠的痒" | 视频的钩子:预期与现实的冲突 | 有没有一个"意料之外"的点? |
| **脑补画面** | 听到就能在脑中放映,暗示时间跨度 | 提示词的可视化度 | 读完能立刻"看见"画面吗? |
| **目标观众和成本** | 基调、受众、成本区间 | 平台/时长/分辨率/算力预算 | 给谁看?几秒?要4K吗? |
| **绝杀片名** | 说清内容又不过于直白 | 标题/首帧/封面吸引力 | 说清内容又不平庸吗? |

反讽是首要要素。没有反讽 = 故事本身有缺陷。

### 主题公式(《电影剧本写作基础》)

```
主题 = 动作 + 人物 = [某个人] 在 [某个地方] 做 [某件事]
```

写不出 = 主题未定,禁止开始分镜。动作先二选一:
- **有形的动作**(physical):追逐、抢劫、竞赛
- **情绪的动作**(emotional):关系崩解、爱与失去

### 一句话概述加强版(合并三书)

```
一个[性格形容词]的[主体],为了[原始欲望],
在[环境/处境]中,对抗[比他略强的障碍/对手]。
```

- **性格形容词**:"谨小慎微的老师"胜过"老师"——形容词注入动机与神态,直接决定模型生成的表演。
- **主角三条硬标准**(《救猫咪》):引发最强冲突 / 情感上有最曲折的路 / 讨大多数人喜欢。

### 原始驱动力(《救猫咪》)——短视频尤其关键

促使主体行动的必须是基本动机:**生存 / 饥饿 / 性 / 保护所爱 / 复仇 / 对死亡的恐惧**。
AI 视频只有几秒,没时间解释复杂动机——只有原始欲望能瞬间被看懂。

**反向测试**:抽掉原始元素后创意是否立刻塌掉?若无损失 = 选题不成立。
人物关系优先选丈夫/妻子、父亲/女儿、前任——"仅仅这些称呼就能立即捕获注意力"。

### 风险测试题(《故事》第38条)——万能创意体检

> "风险是什么?如果主人公得不到他想要的,他将失去什么?"

若答案是"生活回到正常状态",这个故事不值得讲。这是"氛围片无感"的精确解释:**失败了也没损失 = 注定平淡**。
价值越大,风险越大。可见化风险:时间限制、易碎之物、身后逼近之物。

### 10 种故事类型(《救猫咪》)——每类自带镜头指令

类型不是标签,是**规则集**。选定类型 = 选定冲突结构 = 知道镜头该对准什么。

| 类型 | 内核 | 镜头指令 |
|---|---|---|
| 屋里有怪物 | 怪物 + 封闭空间 | **空间必须拍出封闭感**(AI 最易犯错:场景没约束,冲突不成立) |
| 金羊毛 | 旅途中找到自己 | 路上每个事件都要影响主体 |
| 愿望成真 | 心愿被实现 | 主体须是被欺压的灰姑娘型 |
| 陷入困境 | 普通人陷入不普通处境 | 拍出普通人与困境的落差 |
| 人生变迁 | 面对"生活"这个看不见的怪 | 所有人都懂,只有主体不懂 |
| 伙伴情谊 | 两人互补(含所有爱情) | 开场两人必须互相憎恨 |
| 推理调查 | 重点是"为什么"不是"谁" | 观众是侦探,拍人性阴暗 |
| 傻瓜获胜 | 卑微者 vs 权势者 | 反复强调"没人信他能成功" |
| 体制之下 | 群体/体制的故事 | 必有一个突围角色 |
| 超级英雄 | 非凡者在凡人世界 | 给一个"优势带来的代价"细节 |

### 救猫咪时刻——让观众几秒内喜欢上主角

主角出场镜头给一个**具体的、可拍摄的小善举/小幽默动作**(不是"帅气站着")。它同时完成:定义身份 + 赢得好感。
"酷"不等于讨喜。反英雄处理:把对手设计得更坏。

## 二、节拍结构:把时间轴刻度化

**核心洞察**(《救猫咪》《电影剧本写作基础》共识):节拍的**内部比例不变**,可等比缩放到任意时长。

### 15 节拍完整表(《救猫咪》)

| # | 节拍 | 占比 | 作用与操作规则 |
|---|---|---|---|
| 1 | 开场画面 | 0% | 第一印象:基调/情绪/类型/规模;展示主体起点。与终场画面成对且相反 |
| 2 | 阐明主题 | 5% | 通常由非主角说出一句话 = 主题暗示 |
| 3 | 铺垫 | 1–9% | 所有主线人物出场;埋"六大缺憾" |
| 4 | **触发事件** | **11%** | 打破日常。"轰!"短视频里就是前1–2秒 |
| 5 | 讨论/犹疑 | 11–23% | 主体犹疑:我该去吗?此段须提出一个问题 |
| 6 | 进入第二幕 | 23% | **主体必须自己做决定**,不能被拖着走 |
| 7 | 副线 | 27% | 助推器,缓和转幕突兀感,承载主题 |
| 8 | 玩闹和游戏 | 27–50% | "兑现对前提的承诺",海报上的内容 |
| 9 | **中点** | **50%** | 假胜利或假失败;风险升级 |
| 10 | 反派逼近 | 50–68% | 外部压力 + 内部分裂双向夹击 |
| 11 | **失去一切** | **68%** | 最低点,含"死亡气息" |
| 12 | 灵魂黑夜 | 68–77% | 绝望中的沉淀 |
| 13 | 进入第三幕 | 77% | 融合主线副线得到解法 |
| 14 | 结局 | 77–100% | 执行、翻盘;坏人下场从低到高 |
| 15 | 终场画面 | 100% | 与开场相反,证明变化发生 |

### 时长换算表

| 节拍 | 占比 | 15s | 30s | 60s |
|---|---|---|---|---|
| 开场画面 | 0% | 0s | 0s | 0s |
| **触发事件** | 11% | ~1.7s | ~3.3s | ~6.6s |
| 进入第二幕 | 23% | ~3.5s | ~7s | ~14s |
| **中点** | 50% | 7.5s | 15s | 30s |
| **失去一切** | 68% | ~10s | ~20s | ~41s |
| 进入第三幕 | 77% | ~11.5s | ~23s | ~46s |
| 终场画面 | 100% | 15s | 30s | 60s |

极短视频(≤15s)最小节拍集:**开场画面(0%) → 触发事件(11%) → 中点(50%) → 失去一切(68%) → 终场画面(100%)**。

### 三幕范式(《电影剧本写作基础》)

1 页 = 银幕 1 分钟。第一幕建置 0–25% / 第二幕对抗 25–75% / 第三幕结局 75–100%。
情节点 I ≈ 21%,情节点 II ≈ 71%。情节点 = **一个把故事转向另一方向的事变**(不是高潮,是转向)。

### 时长 ↔ 转折数量对应律(《故事》第56条)

与直觉相反:短视频不该塞多个转折,一个就够,但必须是真正的逆转。

| 时长 | 重大逆转数 | 结构 |
|---|---|---|
| 5–15s | **1 个** | 单幕:建立→一次逆转→结束 |
| 15–30s | 1–2 个 | 单幕或两幕 |
| 30–60s | 2 个 | 两幕 |
| 60s+ | 3 个 | 三幕 |

**末段必须最短最快**,给"加速感"。一个 15 秒视频塞 3 次反转 → 每次都被削弱,观众只觉得乱。

### 先定结尾,再定开头(《电影剧本写作基础》)

动笔前先确定四件事,顺序不可颠倒:**结尾 → 开端 → 情节点I → 情节点II**。
分镜表**从最后一镜开始填**,再倒推第一镜。

### 三条铁律

1. **触发事件在 11%**:短视频里前 1–2 秒必须打破日常。
2. **开场画面 ↔ 终场画面必须相反**:一加一减,证明变化。设计不出末镜 = 中段没发生变化。
3. **主体必须主动**进入第二幕。避免"他被卷入",改"他推开门"。

## 三、场景 = 价值转变(镜头级最硬工具)

**这是把"镜头有没有戏"变成可判定问题的工具。** 三本书用三套等价符号,收敛为两个必填字段。

### 场景 = 价值转变(《故事》第9条)

麦基定义:场景是"通过冲突表现出来的一段动作,这段动作会**在人物的生活情境中至少一个具有重要意义的价值上造成转折**"。
> **如果一个场景不能造成转折,应当删掉它。**

价值(value)= 一对可正可负的经验(生/死、爱/恨、自由/奴役、真/假、勇敢/懦弱)。场景开始时价值处于某一极,结束时**必须翻到另一极**。

### 两个必填字段(《救猫咪》符号)

| 字段 | 符号 | 判据 | 填不出 |
|---|---|---|---|
| **价值转变** | `+/-` | 开始情绪极性 → 结束情绪极性,**必须相反** | 无事件,删/并 |
| **冲突** | `><` | 谁 vs 谁/什么,谁赢,**只能一个冲突** | 无戏,删/并 |

**硬规则**(《救猫咪》):想不清 `+/-` 和 `><` 之前,不要写这个镜头。想不清,就把它删了。

### need + obstacle(《电影剧本写作基础》等价表述)

"一切戏剧都是冲突。" 每镜填两格:**主体想要什么(need)** / **什么在阻挡(obstacle)**。先写需求,再写障碍。
一格填不出 = 该镜没有戏剧张力。

### 价值的四层光谱(《故事》第86条)——衡量强度的尺子

```
正面(爱) → 相反(冷漠) → 矛盾(恨) → 负面之负面(伪装成爱的恨,如自我憎恨)
```

越往负面之负面走,张力越大。设计高潮镜头时,把价值推到"负面之负面"这一层。

### 冲突的三个层面(《故事》第36条)——决定景别

| 冲突层面 | 可见化手段 | 推荐景别 |
|---|---|---|
| 内心 | 手的小动作、呼吸、视线躲闪、僵住 | 特写/近景 |
| 个人 | 两人间距、朝向、触碰与回避 | 中景/双人镜 |
| 外界-社会 | 人与人群/建筑/制度符号对比 | 中远景 |
| 外界-环境 | 人与天地/物体体量对比 | 远景/大远景 |

**短视频优先选"外界"或"个人"层面**:更易拍、更易被 3 秒读懂。纯内心冲突需要极强外化功力。

### 相邻高潮必须异号(《故事》第57条)——多镜头情绪硬规则

> "重复是节奏的死敌。不能用上扬结局铺设上扬结局。"

- 末镜为 + → **倒数第二镜必须为 −**(先压到底再翻)。
- 末镜为 − → **倒数第二镜必须为 +**(先给希望再打碎)。
- 情感体验重复时,第二个事件力度减半。这解释了为什么很多 AI 视频结尾"没劲":最后两镜同向递进。

## 四、gap 引擎:让每个镜头都有戏

**这是把平淡画面变成有戏画面的通用公式,而且纯机械可操作。** 是《故事》对本 skill 最实用的贡献。

### 最小保守行动 + 鸿沟(《故事》第35条)

人物总是采取"从他主观视点看最小的、最保守的行动",期待世界给出有益反应——但故事里,**反应必须不合预期**。期望与结果之间的落差 = **鸿沟(gap)**。

```
镜头 = 主体的最小保守行动 → 世界的意外反应(鸿沟)
```

- 例:她轻轻推门(最小行动)→ 门自己向内洞开,里面空无一物(意外反应)。
- 例:他伸手接住飘落的信 → 信在指尖碎成灰。

这条同时解释了"为什么 AI 视频看着没劲":动作与结果完全符合预期 = 无鸿沟 = 无戏。

### 行动 vs 活动(《故事》第37条)——什么值得拍

| | 定义 | 是否值得拍 |
|---|---|---|
| **行动** | 在期望中开掘鸿沟、创造有意义的变化 | ✅ 拍 |
| **活动** | 所期望的都会发生,无变化或只有细微变化 | ❌ 不拍 |

大量 AI 视频拍的都是"活动"(走路、微笑、喝咖啡、看窗外)。**自检:每镜的动作是"行动"还是"活动"?是活动 → 删或改。**

### 生成鸿沟的万能提问(《故事》第41条)——一步把平庸改成有戏

```
1. 写出主体的动作
2. 写出观众/模型会默认预期的反应
3. 问:"这个反应的对立面是什么?"
4. 用对立面替换 → 镜头立刻有了鸿沟
```

- 例:她推开门 → 预期:门开了,里面有人 → 对立面:门开了,里面是另一扇一样的门。
- 例:他伸手接雨 → 预期:雨落在掌心 → 对立面:雨在离掌心一寸处停住。

**对 AI 视频极其有用**——因为模型的默认输出就是"预期反应"。取其对立面,就跳出了平庸。

### 鸿沟递进 = 多镜头骨架(《故事》第37条)

```
镜1: 主体最小行动 → 意外反应(小鸿沟)
镜2: 更冒险的行动 → 更强的意外(中鸿沟)
镜3: 最冒险的行动 → 最终结果(大鸿沟/高潮)
```

风险与赌注必须**逐镜升高**(《故事》第53条"不归点":每镜动作强度单调递增),否则观众感到重复。

### 强调"反应"而非"发生了什么"(《故事》第42条)

> "优秀的写作不太强调发生了什么,而是强调发生于谁、为什么、如何。最丰富的愉悦来自聚焦于**事件导致的反应**的故事。"

麦基的诊断:一个人敲门、门就直接开了 = "八秒钟的死镜头",剪辑师会剪掉。**AI 视频最实用的诊断标准:这一镜拍的是反应,还是只是'发生了一件事'?**

## 五、show don't tell 与潜文本

### "能被摄影机拍到吗"(《电影剧本写作基础》)

电影 ≠ 小说 ≠ 戏剧。想法/回忆/心情/身份/关系都不能直接拍。逐句检验:**这句能被镜头拍到吗?** 不能 → 改写成可拍画面。

| 想表达(抽象) | 改写为(可拍) |
|---|---|
| 他很痛苦 | 猛击墙壁→踢翻纸篓→贴墙下滑 |
| 夫妻关系出问题 | 丈夫的目光追着路过的年轻女子 |
| 他曾是职业球员 | 墙上的球队合影 + 他走路一瘸一拐 |
| 陷入回忆 | 镜头落在他失焦的眼神特写,再切闪回 |
| 他很孤独(独处) | 具体行为:对着微波炉发呆、给一株枯萎的植物浇水 |

### 从里面写到外面(《故事》第39条)——两步法

```
第一步(不进提示词):问"如果我是这个人物,此刻我会怎么做?"写出内心独白
第二步(进提示词):只保留可被镜头拍到的言行——动作、表情、身体细节、与物的互动
```

这样得到的动作细节既具体又不陈腐,且天然带潜文本。多主体镜头:在每个主体的视点上各走一遍,避免配角像背景板。

### 潜文本 = 双层动作(《故事》第40、67条)

潜文本不是玄学:它是"内心 A + 外显 B"的具体落差,可写成明确画面指令。

```
提示词写法:[外显动作/表情] + [泄露真实内心的细节]
```

- 例:"她笑着说没关系(外显),手指无意识地把项链绞紧(泄露)"。
- 例:"他语气平静地点烟(外显),点第二次才点着(泄露)"。

这类"双层动作"极大提升 AI 视频的表演质感,且是模型能拍出来的具体指令。

### "换轮胎"改写术(《故事》第68条)——最实用的一条

要拍抽象情感(如"爱")时,**让人物去做一件具体的、看似无关的杂事**(换汽车轮胎),把每个动作都关于那件杂事,情感 X 从缝隙里渗出来。
完美匹配 AI 视频:模型擅长渲染具体动作,拙于渲染抽象感觉。

### 解说转化为弹药(《故事》第87条)+ 泳池里的教皇(《救猫咪》)

需要交代背景时,**不要用字幕/旁白硬讲**,而要把信息藏进一个反常的、有看点的视觉情境里(教皇穿泳衣在梵蒂冈泳池里游),观众忙着看奇观,信息就交代完了。

## 六、进展与转折:多镜头的节奏

### 转折,转折,转折(《救猫咪》诊断)

剧情不能只直直向前,要**一边推进一边改变方向和增强强度**(匀速 vs 加速)。
**关键判据:即使画面很动,依然可能没有故事。** 这正是 AI 视频最典型的失败——画面很动,但什么也没发生。多镜头序列必须每一镜改变方向或加强强度。

### 进展 = 价值振荡(《故事》第30、76条)

进展不是一路上升,而是在正/负价值之间**动态往复**——紧张与松弛交替脉动。一路上升会让观众疲劳。向高潮时,**场景长度缩短、速度加快**(《故事》第77条)。

### 情节点 = 处境翻面(《电影剧本写作基础》)

定位转折点只问一句:**这一刻主体的处境是否翻到了反面?**(受害者→反击者 / 完成任务→被陷害 / 旁观→卷入)。

### 转换原理:两镜之间的"第三要素"(《故事》第80条)——AI 多镜头衔接核心

两个镜头之间要顺畅衔接,必须有一个**第三要素**做铰链——两镜共有的某种东西(一个物体、一句话、一个动作、一种情绪、光线、形状)。这与《以眼说话》的"对比与相似"、《分镜头脚本设计教程》的"关联剪辑"完全同源。写多镜头时,显式设计相邻两镜共享的桥接元素。

### 情感色轮:修复单调(《救猫咪》诊断)

序列情绪单一时(全燃/全治愈),**保留镜头的动作、+/-、冲突不变,只替换情绪色彩**(用欲望代替大笑、用嫉妒代替直白冲突)。低成本高收益。

### 回报递减(《故事》第65条)

同一种情感不能连续重复——第二次出现力度减半。多镜头序列要让情感种类有变化。

## 七、结构类审查清单

综合三本书,可勾选:

```
立意:
[ ] 能用一句话说清吗?(logline 四要素齐全?)
[ ] 核心动作挂在原始欲望上吗?(抽掉后是否塌掉?)
[ ] 风险测试:主体失败会失去什么?答不出 = 创意不成立
[ ] 选定了类型/冲突层面吗?

节拍:
[ ] 触发事件在 ~11%?(短视频前1–2秒)
[ ] 转折数量匹配时长?(≤15s 只要1个真逆转)
[ ] 末段最短最快、有加速感?
[ ] 开场画面 ↔ 终场画面相反?

场景之戏:
[ ] 每镜能填出 +/-(极性翻转)?填不出 → 删/并
[ ] 每镜能填出 ><(一个冲突)?填不出 → 删/并
[ ] 每镜是"行动"(有鸿沟)还是"活动"(无变化)?活动 → 删
[ ] 相邻高潮异号?(末镜前一镜与末镜相反?)
[ ] 高潮镜头价值推到"负面之负面"了吗?

可拍性:
[ ] 有无法拍摄的抽象表述吗?(想法/心情/关系 → 改可拍动作)
[ ] 用字幕/旁白硬讲设定了吗?→ 改反常视觉情境
[ ] 关键情感用"换轮胎"式具体动作外化了吗?
[ ] 微表情用"双层动作"(外显+泄露)写了吗?

进展与衔接:
[ ] 画面很动但没推进?(每镜改变方向或加强强度?)
[ ] 情感是否单一?→ 用情感色轮补缺失色彩
[ ] 相邻两镜有共享的"第三要素"做铰链吗?
[ ] 主体是动作发起者,还是被环境推着走?
```
