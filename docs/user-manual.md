# Drama Agent 使用手册

面向**实际操作这个平台的用户**——不需要读代码，跟着本手册的步骤就能用 Drama Agent
把一段文字变成一支短剧。开发相关的架构说明见 [README.md](../README.md)，
本手册只讲界面上能看到、能点的东西。

---

## 一、快速上手

### 1. 部署

```bash
uv sync --extra dev            # 后端依赖
cd frontend && pnpm install    # 前端依赖
cp .env.example .env           # 复制配置模板
bash start.sh                  # 前后端一起启动
```

打开浏览器访问 `http://localhost:5173`。

### 2. 首次配置：至少接一个视频模型

不配视频模型，流水线跑到「生成视频」那一步会失败。两种方式二选一：

- **改 `.env`**：填 `ARK_API_KEY` + `SEEDANCE_ENDPOINT_ID`（火山引擎 Seedance），
  或 `MINIMAX_VIDEO_API_KEY`（MiniMax H3），改完重启后端生效。
- **在界面配**（推荐，改完立即生效，不用重启）：进「模型管理」页，找到对应的
  内置 provider（如「字节跳动」），点「编辑」，填 API Key，保存。

文本模型（LLM）同理，内置走 `DRAMA_API_KEY`（DeepSeek）。图像模型是可选的——
只有需要 AI 生成角色造型 / 素材图时才用得到。

### 3. 核对配置

进「模型管理」页，确认至少有一个视频模型和一个文本模型显示为已启用、
没有「未配置凭证」的提示。

## 二、核心概念（30 秒理解）

| 概念 | 一句话 | 你在哪里看到它 |
|------|--------|----------------|
| **作品** | 一部剧的容器，可以有很多集 | 首页「作品列表」 |
| **故事** | 你写的原文，可以反复改编出不同的剧本 | 顶部导航「故事」 |
| **剧本** | 一段原文的一个改编方案（具体台词、场景） | 从故事页「查看」进入 |
| **集** | 一条独立的制作流水线，认准一份剧本来拍 | 作品详情页的列表 |
| **角色 / 造型** | 人物身份 + 他的不同穿着打扮 | 「角色管理」页 |

**记住这一句就够了**：故事是原材料，剧本是加工方案，集是具体的一次拍摄。
同一段故事可以改出好几个剧本，一个剧本也可以被多集复用（比如想用不同的
视频模型各拍一遍对比效果）。

## 三、完整剧集模式：从一段故事到一支短剧

这是最常用的路径，适合正式产出一集完整短剧。

### 步骤 1：新建作品

首页点「新建项目」，填：

- **剧名**（必填）
- **故事类型**（下拉选，默认「剧情」）
- **小说正文**（可选）——如果你要用一整本小说批量产出很多集，把全文贴在这里；
  如果只是写单集故事，留空，直接在下一步的「新建创作」里写。
- 填了小说正文的话，还要填**期望集数**或**每集时长**（二选一）

提交后跳到作品详情页。如果贴了小说正文，页面上会出现「开始改编」的入口
（见下方「小说改编」小节）；没贴的话，直接点右上角「新建创作」开始写第一集。

### 步骤 2（可选）：小说改编——一次批量切出很多集

如果你在新建作品时贴了小说正文，作品详情页顶部会有一张改编面板：

1. 点「开始改编」，系统先识别全书出现的角色
2. 等一会儿会进入「确认角色身份」——把小说里认出来的人物名字与你作品库
   里已有的角色对上号（或新建），这是切分前**唯一**需要你手动确认的地方
3. 确认后系统继续把全书按你设定的集数/每集时长切成 N 段，每段直接落成
   一个剧本方案，不需要再审一遍
4. 切完后面板列出这 N 个剧本片段，点「建出 N 集」一次性建好这些集
   （建完之后，这些集就进入下方的「新建一集」流程，各自独立开拍）

改编开始后小说正文会被锁定（防止改了原文却没重新改编，产生错位）；
如果切分结果不满意，可以点「重新改编」再来一次。

### 步骤 3：新建一集

在作品详情页点「新建创作」，你会看到两个单选：**完整剧集** 和 **直接生成**。
本节讲「完整剧集」，「直接生成」见下一大节。

选「完整剧集」后填：

- **本集标题**（必填）
- **拍哪段原文**——下拉选一个已有故事，或直接在下面的文本框粘一段新故事
- **文本模型 / 视频模型 / 分辨率 / 画面比例 / 目标时长**——一般用默认值即可
- **关键帧先行**开关——打开的话，视频生成前会先出一批静态关键帧图给你审核，
  确认没问题才真正生成视频（多一道审核，但能省视频生成的返工成本）

提交后进入剧集详情页，页面左侧是流水线步骤条，右侧是当前步骤的内容。

### 步骤 4：开拍

剧集详情页点「开始制作」。制作是在后台跑的，你可以关掉页面，
回来的时候通过左侧步骤条能看到跑到哪一步了。

### 步骤 5：依次过人工卡点

流水线在几个地方会停下来等你确认，每停一处右侧就会出现对应的审核面板：

| 卡点 | 你要做什么 |
|------|-----------|
| **确认角色身份** | 剧本里出现了角色库之外的新人物，逐个选「关联到已有角色」或「新建为新角色」；这里还能顺手生成这些角色的形象 |
| **审核剧本** | 读一遍生成的剧本正文，满意点「通过」；不满意点「修改」写修改意见，或用右侧的 AI 改写助手对话式调整，也可以「存为改编方案」存回故事库供以后复用 |
| **审核分镜** | 检查分镜表（景别/运镜/时长/描述），如果总时长超出目标会有提示；满意点「通过，继续造型」，不满意「退回重新生成」并说明理由 |
| **审核造型** | 确认每个场景里各角色穿的是哪套造型，可以在下拉里改选，确认后点「确认造型」 |
| **审核 Prompt** | 逐镜检查即将发给视频模型的具体提示词，可以直接在文本框里改，改完「全部确认，开始生成视频」 |
| **审核关键帧**（若开了这个选项） | 看每镜的静态关键帧图，不满意的勾选后「重生成所选」，都满意就「确认，生成视频」 |

### 步骤 6：查看成片

视频生成完成后，「生成视频」步骤下能看到每个镜头的生成进度和播放器；
全部完成后「完成」步骤会出现完整成片，可在线播放、下载。
如果某几镜生成失败，成片会自动跳过它们拼接，页面会提示具体缺了哪几镜，
点提示可以跳到对应镜头单独补生成（见下方「视频产物操作」）。

## 四、直接生成（简单模式）：跳过流水线，秒出一支视频

适合快速验证一句 prompt 的效果，或者你已经很清楚想要什么画面，不需要
LLM 帮你分析剧情、写剧本、分镜头。

1. 在作品详情页点「新建创作」，选「直接生成」
2. 输入框里直接写你想要的画面描述（这是真正发给视频模型的提示词，不会被
   LLM 加工）
3. 需要参考图/参考视频的话，用 `@` 呼出候选列表——可以引用素材库里的图、
   本项目已有的图、或者本项目之前生成过的散片（作为参考视频），也可以直接
   拖拽上传图片或视频文件
4. 每条引用的图会带一个用途下拉：**首帧 / 尾帧 / 主体参考**，按需选；
   参考视频没有这个下拉，用途由下面的「模式」决定
5. 底部参数条按需调整：
   - **模式**：参考生成（默认）/ 视频编辑 / 视频延长——后两种只在选的模型
     支持参考视频、且你已经配置了对象存储时才能用（见下方「存储管理」）
   - 视频模型 / 分辨率 / 画面比例 / 时长——选项都会随模型变化，某些组合会
     互相禁用（比如选了「视频编辑」模式，时长会锁定为跟原视频一致）
   - 需要的话展开「负向提示词」，写你不想出现的元素
6. 点发送提交，下方画廊里会出现一张新卡片，显示生成状态；完成后可直接
   在卡片里播放、下载，不满意可以删除重来

散片不会自动合成进任何剧集，也不会进素材库——它就是一支独立的视频。

## 五、角色与素材管理

### 角色与造型

进「角色管理」（在作品详情页点「角色管理」进入）：

1. 「新建角色」——填名字和描述即可，描述可选（后续剧本里提到这个角色时，
   AI 抽出的外貌描述会自动补充展示）
2. 给角色配音色（可选）——上传一段 2~15 秒的 wav/mp3，之后这个角色说话的
   镜头可以带上这个音色
3. 「新建造型」——给角色建一套服饰/发型方案，可以设为默认造型
4. 每套造型下面是正面/侧面/背面/面部特写四格图，两种方式补图：
   - **AI 生成四视图**——填角色描述和造型描述，一次生成一整张图，
     系统会自动切成四格；切不开的话会自动转成手动裁切界面，不需要重新生成
   - **从素材库导入**——挑素材库里已有的人物图，尝试自动裁切成四视图

角色形象建好之后，分镜生成视频时会自动带入对应造型的参考图，不需要每次
手动传。

### 素材库

顶部导航「素材库」，四个分类：人物 / 背景 / 道具 / 服饰。

- **直接上传**——选分类、填名称、传一张图
- **AI 生成**——选图像模型 → 选分类（会自动带出该分类的推荐写法，比如
  背景类会自动加上「画面无人物」的约束）→ 写描述 → 生成 → 满意就填名称
  保存
- 已有素材可以「AI 改图」：写改图要求（比如「改成夜晚场景」），生成后
  另存为一张新素材，原图不受影响

素材库是全局共享的，任何作品都能用它里面的图。

## 六、模型管理与存储管理

### 模型管理

顶部导航「模型管理」，按文本 / 视频 / 图片三类列出所有已配置的模型 provider。

- **内置 provider**（如「字节跳动」「MiniMax」）不能删，只需要填 API Key
  就能用，地址是锁死的官方地址
- **新增自定义 provider**——如果你接的是某个网关代理商（不是厂商官方地址），
  填 Provider ID、协议（按你对接的服务选，如 `seedance`/`minimax`）、
  Base URL、API Key
- **自定义接入路径**（高级选项，一般不需要）——如果这个网关把接口挂在了
  跟官方不一样的路径上，或者返回的字段结构不一样，勾选这个选项，
  分别填「接入路径」（留空就是走官方默认路径）和「响应字段映射」（告诉
  系统去哪个字段读任务 ID / 状态 / 视频地址）。详细说明见附录「自定义接入路径」
- 每个 provider 下面可以加多个模型，选一个设为默认；模型的分辨率/时长
  区间/支持的动作等能力都在这里声明，界面上其它地方（分镜生成、直接生成、
  产物树动作）都会按这里的声明自动调整可选项

### 存储管理

顶部导航「存储管理」。**什么时候需要配**：只有当你要用「直接生成」的
视频编辑/延长模式时才需要——因为视频模型只接受公网 URL 的参考视频，
不配存储的话这两个模式在界面上是禁用状态（会提示原因）。

「新建」需要填：Provider ID、名称、后端（如腾讯云 COS）、Bucket、Region、
SecretId、SecretKey。图片/音频参考不受这个开关影响（默认走内联传输）。

不需要用视频编辑/延长功能的话，这个页面可以完全不管。

## 七、视频产物操作（重跑 / 改参重生 / 升清）

在剧集详情页「生成视频」步骤，每个已生成的镜头下面都有一个「版本树」区域，
列出这个镜头目前有哪些生成版本，选中一个版本后会出现该版本当前可用的操作：

| 操作 | 会问你什么 | 适合什么场景 |
|------|-----------|-------------|
| **相同 prompt 重跑** | 不用填任何参数 | 上次生成的效果不稳定，想用完全相同的设定再抽一次 |
| **改参数重生** | 分辨率 / 时长 / Prompt（默认沿用上一版） | 想调整某个参数看效果，比如改一下提示词措辞 |
| **升清 2K** | 不用填参数 | 想要更高分辨率的版本；只有分辨率恰好是 768P、且当前模型支持时才会出现这个选项 |

每次操作都会生成一个新版本，挂在原版本下面，不会覆盖旧版本——想对比效果
的话可以在版本树里切换查看。

> 注意：视频编辑 / 延长不在这里，那是「直接生成」（散片）里的功能，
> 见上方第四节。

## 八、常见问题

**Q: 视频模型下拉里显示「未配置凭证」，选不了？**
去「模型管理」找到对应 provider，编辑填上 API Key。

**Q: 视频编辑 / 视频延长两个模式在直接生成里是灰的？**
先去「存储管理」配一个对象存储；也可能是当前选的视频模型本身不支持参考视频
（`max_reference_videos` 为 0），换个模型试试。

**Q: 分镜/剧本生成失败了怎么办？**
流水线的失败会显示在左栏的「错误信息」卡片里，读一下报错原因（通常是模型
凭证问题或网络超时）；可以在剧集详情页重新触发该步骤，不需要从头再来一遍。

**Q: 成片里少了几个镜头？**
点成片卡片上的提示链接，跳到「生成视频」步骤，找到失败的那几镜，用上面
「版本树」的「相同 prompt 重跑」补跑一次即可，不用重新合成整个成片。

**Q: 本地起服务，改完代码没生效 / 反复报同一个错？**
先确认端口没被占用（尤其是重启后马上又起，旧进程可能还没退干净）；
本项目的后端不建议用 `uv run uvicorn` 直接起，`start.sh` 里已经处理好了，
按 README 的启动方式来就不会遇到这个问题。

**Q: 想批量产出很多集，但没有一整本小说，只有分散的几段故事？**
「小说改编」只适用于一整本贴进去自动切分的场景。如果故事是分散写的，
就用「新建创作」→「完整剧集」逐条建，每条各自选择要拍哪段原文即可。

## 附录：自定义接入路径

「模型管理」页支持「自定义接入路径」这个高级选项，只在你接的视频/图像/文本服务
走的是同一协议但**路径不同、返回结构也不同**（比如接的是某个网关中转、而不是
厂商官方地址）时才需要用。多数人可以跳过这一节。

### 要解决什么问题

同一个协议可能被不同网关代理，各家把接口挂在**不同路径**上、响应结构也
**各有包装**，但请求体本身通常一字不差。这种情况下不需要为每个网关单独建一个
"协议"，只需要告诉系统：这条 provider 的路径不一样、返回结构不一样，
路径和结构分别是什么。

### 怎么填

勾选「自定义接入路径」后展开两块：

**接入路径**——按你选的协议列出该协议认的功能键（比如视频协议是
「提交任务路径」「查询任务路径」），每项旁边显示官方默认路径作参考。
**留空就是走官方默认路径**——只需要填与官方不同的那几项。

**响应字段映射**——语义字段是固定的几个（任务 ID / 状态 / 视频地址 /
尾帧地址 / 错误信息 / seed），你要填的是这些字段在**这个网关的返回 JSON
里的实际位置**，用 `.` 分层、数字表示数组下标（比如视频地址嵌在数组第一项
里就填 `content.0.video_url`）。如果这个网关表示"成功""失败"用的词跟官方
不一样，还可以额外填"成功状态词"和"失败状态词"这两项做映射。**同样只需要
填不一样的那几项**，没填的字段走协议默认。

### 不填会怎样

两项都留空 = 完全按协议官方默认实现调用（包括走官方 SDK），行为跟没有这个
高级选项时完全一样。只有你填了对应功能键之后，那一项才会改走直接 HTTP
调用你填的路径、按你填的映射解析响应，没填的功能键仍然走默认——不会因为
你填了别的功能键就影响没填的那些。
